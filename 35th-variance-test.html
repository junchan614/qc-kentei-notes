QC検定2級 過去問解説 / 第35回 問1

含有率のばらつきは小さくなったか — 母分散の片側(下側)χ²検定

「小さくなったかどうか」を調べる検定は片側検定になり、しかも棄却域は分布の小さい値側に来る。10個のサンプルの含有率データからこの一問を解きながら、選択肢が「正しい値とその逆数」のペアで並べられていることまで見抜く。

問題

設定

A社で生産している薬品に含まれる化学成分Qの、これまでの含有率x(%)の母分散はσ0²=0.32(基準値)だった。この基準値と比べて母分散σ²が小さくなったかどうかを検討するため、生産設備を変更した後、10個のサンプルをランダムに抜き取って含有率xを測定した。

STEP 1

仮説を立てる — (1)

帰無仮説H0は「変化していない」という主張なので、必ず等号「=」を含む標準形で書く。これだけで選択肢はア・イ・ウの3つに絞れる。問題文が問うているのは「小さくなったか」であり、「変わったか」でも「大きくなったか」でもない。

✕ア. H1: σ²≠σ0²(両側) … 「変化したか」を問う形。方向を指定していないので、この問題には合わない。
✓イ. H1: σ²<σ0²(下側) … 「小さくなったか」と方向まで一致する。これが正解。
✕ウ. H1: σ²>σ0²(上側) … 「大きくなったか」を問う形。問題文と逆方向。
✕エ・オ・カ … H0に不等号(≠, <, >)が入っている時点で標準形ではない。帰無仮説は常に「等しい」という主張から出発する。
(1) イ. H0: σ² = σ0², H1: σ² < σ0²
STEP 2

検定統計量を求める — (2)

まず偏差平方和Sを「2乗の和 − 補正項」の形で求め、それを基準値σ0²で割ればχ0²になる。Vやnで割ってから比べるのではなく、平方和Sをそのまま使う点に注意。

偏差平方和 S = Σx² − (Σx)²/n = 49.12 − 22.0²/10 = 49.12 − 48.4 S = 0.72
検定統計量 χ0² = S / σ0² = 0.72 / 0.32 χ0² = 2.25
(2) オ. 2.25
STEP 3

棄却限界値と判定 — (3)(4)

下側検定なので棄却域は分布の左裾に置く。自由度φ=n−1=9のχ²分布で、上側95%点(=下側5%点)を付表から引く。

棄却限界値(付表) χ²(9, 0.95) = 3.325　(自由度9で、上側の面積が0.95になる点 = 下側5%の境界)
判定 χ0² = 2.25 < χ²(9, 0.95) = 3.325 → 棄却域に入る 帰無仮説 H0 は棄却され、母分散は小さくなったといえる
(3) イ. 棄却 (4) キ. 小さくなった
直感に反しやすい点: 通常「検定統計量が大きいほど有意」というイメージを持ちがちだが、下側検定では逆に検定統計量が小さいほど有意になる。仮説の向き(H1がどちら向きか)を先に確認してから棄却域の位置を決めること。
分析

選択肢は「正しい値」と「その逆数」のペアでできている

(2)の6つの選択肢を並べてみると、2数の積がほぼ1になる3組のペアになっている。分子と分母を逆にする(χ0²=σ0²/Sとしてしまう)という典型的なミスを想定した作り方だとわかる。

選択肢のペア構造
値逆数判定原因の候補
オ. 2.25イ. 0.444 正解 / 逆数トラップ χ0²=S/σ0²=0.72/0.32。逆にするとχ0²=σ0²/S=0.444になる
カ. 7.031ア. 0.142 誤 / その逆数 σ0=0.32を標準偏差と誤解し2乗(0.32²=0.1024)。0.72/0.1024=7.031になる。問題文の「σ0²=0.32」は既に分散であり、これ以上2乗してはいけない
エ. 1.620ウ. 0.617 誤 / その逆数 1.620×0.617≒1で、同じ「逆数ペア」の構造。具体的な計算過程は一通りに決まらないが、他の2組と同じ罠の系列にある値
検算のコツ: χ0²=S/σ0²で、Sは基準値σ0²よりわずかに大きいはず(データのばらつき自体は残っている)なので、χ0²は1より少し大きい程度の値になる。2.25はその範囲に収まるが、7.031のように極端に大きい値が出たら「σ0とσ0²を取り違えていないか」を疑うとよい。
補足

上側検定との対比

母分散の検定はいつも下側とは限らない。「ばらつきが増えたか」を問う場合は上側検定になり、棄却域は右裾に来る。同じχ²検定でも「何を示したいか」で棄却域の向きが変わることは、母平均のt検定と母分散のχ²検定を並べて上側/下側の対比を扱った第40回問1でも詳しく解説している。

χ0²=S/σ0²そのものの正体(標準化した誤差の2乗和であること、自由度がn−1になる理由)は「χ0²=S/σ0²は何を測っているのか」で掘り下げている。
要点

この問題から持ち帰ること

1H0は必ず「=」を含む標準形。方向(<, >, ≠)はH1側に書く。
2母分散の検定統計量はχ0²=S/σ0²(平方和Sをそのまま使う。Vやnで割らない)。
3「小さくなった/向上した」を示したい検定は下側検定、棄却域は分布の左裾。「大きくなった」は上側検定。
4σ0²と書かれていれば、それは既に分散。2乗し直さない。σ0(標準偏差)が与えられたときだけ2乗して分散にする。
5選択肢に「近い値の組」が並んでいたら、分子分母の逆転や単位の取り違えを想定した罠である可能性を疑う。
