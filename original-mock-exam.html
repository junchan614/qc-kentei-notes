問1 ・ 検定と推定

2つの母平均の差の検定(片側)

ある部品の破断強度(kg)について、旧ラインAと新ラインBのどちらが優れているかを確かめるため、それぞれから無作為にサンプルを取り測定した。過去の実績から新ラインBは改善されたはずだと期待していたが、担当者は「Aの方が高い数値が出ている」と感じたため、母平均はAの方がBより大きい(μA > μB) といえるかを有意水準5%で検定する。両ラインの母分散は等しいとみなせるものとする。

解き方

① φ = nA+nB−2 = 10+8−2 = 16

② Ve = {(nA−1)VA+(nB−1)VB}/φ = (9×4.20+7×3.60)/16 = 63/16 = 3.94

③ t0 = (x̄A−x̄B)/√{Ve(1/nA+1/nB)} = 2.5/√(3.9375×0.225) = 2.5/0.9412 ≒ 2.656

④ t0(2.656) > t(16,0.05)(1.746) なので棄却域に入り、有意水準5%で有意(AはBより優れているといえる)。「μA>μB」という片側の対立仮説なので、両側のt(16,0.025)ではなく片側のt(16,0.05)を使う点に注意。

⑤⑥ 信頼区間は両側なので t(16,0.025)=2.120 を使う。幅 = 2.120×0.9412 ≒ 2.00。区間 = 2.5±2.00 = [0.50, 4.50]。区間が0をまたがない(0を含まない)ことも、④の有意という結論と整合している。

⑦ 「本当は差がないのに、あると判定してしまう」のは第一種の過誤。逆に「本当は差があるのに、ないと判定してしまう」のが第二種の過誤(ぼんやりものの誤り)。

問6 ・ QC的問題解決・QC七つ道具

層別で読む不適合の発生状況

樹脂成形品の「キズ」の発生について、生産設備(機械A・B・C)と勤務帯(昼勤・夜勤)で層別した発生件数を集計した。この結果から、次の調査の方向性を考える。

昼勤夜勤計
機械A12820
機械B5611
機械C31619
計203050
  1. 1機械×勤務帯の組合せ(層)の中で、発生件数が最も多いのはどれか。
  2. 2機械別合計が最も多いのはどれか。
  3. 3勤務帯別合計が最も多いのはどれか。
  4. 4機械Aは昼勤(12)が夜勤(8)より多いのに対し、機械Cは夜勤(16)が昼勤(3)より圧倒的に多い。この層別結果から読み取れることとして最も適切なものを選べ。
  5. 5機械別件数を多い順に並べたパレート図を作るとき、上位2機械(A・C)で全体の何%を占めるか(小数点以下0桁)。
    %
  6. 6次にとるべき調査として最も適切なものはどれか。

解き方

①②③ 表を素直に読む。最多の層は機械C×夜勤(16件)、機械別合計の最大は機械A(20件)、勤務帯別合計の最大は夜勤(30件)。

④ 機械別だけ・勤務帯別だけの合計を見ても、機械Aと機械Cで「昼夜どちらが多いか」が逆転していることには気づけない。層別してクロス集計することで初めて、機械Cと夜勤の組合せに固有の原因がありそうだと分かる。これが「層別で真因にたどり着く」というQC的問題解決の考え方の核心。

⑤ 機械別上位2つ(A=20, C=19)の合計=39。39/50=0.78=78%。

⑥ ④の示唆を受けて、次は機械C×夜勤に絞ってさらに層別データを集めるのが合理的。母集団を広げる(全機械・全勤務帯を調べ直す)のは、すでに得られている手がかりを無視することになる。
