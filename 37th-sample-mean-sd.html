QC検定2級 / 第37回 問2 (13)

なぜ√nで割るのか

「9個のサンプルの平均値の標準偏差」を聞かれている。答えは 1.414 ÷ 3 = 0.471 だが、なぜ 9 ではなく √9 = 3 で割るのか。ここが腑に落ちれば、区間推定も検定も同じ道具で読めるようになる。

問題

(13)は何を聞いているのか

平板Cの厚みは 平均30mm、標準偏差 1.414mm の正規分布に従う（これが(11)の答え）。
この工程から 9個 サンプルを取り出して、それらの厚みの平均値を求めるとき、
その平均値の分布は平均30mm、標準偏差 (13) mm の正規分布に従う。

まず押さえたいのは、「平均値」もばらつくということ。9個取って平均を出す、という作業をもう一度やれば、違う9個が取れて、平均値も違う値になる。何度も繰り返せば平均値そのものが分布を作る。(13)はその分布の広がりを聞いている。

用語: この「平均値の標準偏差」を標準誤差と呼ぶ。個々のデータの標準偏差 σ とは別物なので、頭の中で区別しておく。記号で書くと σx̄ = σ / √n。
図解

1枚のばらつきと、9枚平均のばらつき

同じ横軸に、①平板1枚の厚みの分布 と ②9枚の平均値の分布 を重ねて描くと、何が起きているかが一目でわかる。

核心

なぜ 9 ではなく √9 なのか

鍵は「足し算ができるのは標準偏差ではなく分散」という一点。標準偏差のままでは足せないので、いったん分散に変換して計算し、最後に√を取って標準偏差に戻す。

式にすると V(x̄) = V(合計) / n² = n·σ² / n² = σ² / n σ(x̄) = √(σ²/n) = σ / √n
今回の値を代入 …(13) σ(x̄) = 1.414 / √9 = 1.414 / 3 ≒ 0.471
(13) 0.471
補足

なぜ n ではなく n² で割るのか

「合計を9で割って平均にするなら、分散も9で割ればいいのでは」と思うところ。ここでつまずくのは自然で、原因は分散が「2乗した世界」の量であるという一点にある。

覚えるべきルールはこれだけ データを c 倍すると … 標準偏差は c 倍、分散は c² 倍

平均を出すという操作は「合計を 1/9 倍する」こと。つまり c = 1/9 なので、標準偏差は 1/9 倍、分散は (1/9)² = 1/81 倍になる。分散の側だけ2乗が付くのは、分散がズレを2乗して測っている量だから。ズレが 1/9 になれば、その2乗は 1/81 になる。

数値でも確かめておく。データ全体を2倍すると何が起きるか。

ズレが2倍になれば、それを2乗した分散は4倍になる。この関係が c 倍のときは c² 倍、1/9 倍のときは 1/81 倍として効いてくる。

単位で確認する方法: 厚みの単位が mm なら、標準偏差の単位も mm、分散の単位は mm²。長さを 1/9 にすれば面積は 1/81 になる、という当たり前の話と同じこと。分散の式に 2乗が出てきたら「面積の話をしている」と思い出すとよい。
n² を経由しない見方もある: 平均を x̄ = (1/9)X₁ + (1/9)X₂ + … + (1/9)X₉ と書き直すと、各項の分散は (1/9)² × 2 = 2/81。これを9個足して 9 × 2/81 = 2/9。同じ答えにたどり着く。どちらの道でも、1/9 倍のところで必ず2乗が出るのがポイント。
つながり

(11)と(13)は同じ道具を使っている

実はこの問題、(11)でも(13)でも「分散で計算して最後に√を取る」という同じ手順を踏んでいる。違うのは足すのか割るのかだけ。

感覚

√で効くとはどういうことか

サンプル数を増やせば平均値のばらつきは小さくなる。ただし√でしか効かないので、思ったより減らない。この感覚は実務でも試験でも効く。

要点

この設問から持ち帰ること

1平均値もばらつく。 サンプルを取り直せば平均値も変わる。その広がりが標準誤差 σ/√n。個々のデータの σ とは別物。
2足せるのは分散だけ。 標準偏差のまま足したり割ったりしない。分散に直す → 計算する → √を取って戻す、の3手順を固定する。
3分散は 1/n、標準偏差は 1/√n。 どちらの世界の話をしているか意識すれば、n で割るか √n で割るかで迷わない。
3′c 倍すると標準偏差は c 倍、分散は c² 倍。 分散が「ズレを2乗した量」＝面積のような量だから。式に n² が出てくるのはこのルールの現れで、特別な決まりごとではない。
4中心は動かない。 平均値の分布の平均は、元の分布の平均と同じ30mm。動くのは広がりだけ。
5この式は後の単元の土台。 母平均の区間推定 x̄ ± u(または t)×σ/√n も、平均値の検定も、すべてこの σ/√n が中に入っている。ここが曖昧だと後半の単元が全部あやふやになる。
