概念の掘り下げ / 第35回 問3 関連

相関係数はなぜ r = S(xy)/√(S(xx)·S(yy)) という形になるのか

「分子は偏差積和、分母はxとyの偏差平方和の積の平方根」という式は暗記すると回帰係数β1の式(S(xy)/S(xx))と混同しやすい。ここでは分子が何を測っているかと、分母がその値を必ず−1〜1に収める理由を、回帰直線の残差平方和が0以上であるという1つの事実から導く。

①

分子S(xy)は「同じ方向に動いたか」を数えている

S(xy) = Σ(xi−x̄)(yi−ȳ) は、各点についてxの偏差とyの偏差を掛けて足し合わせたもの。1点ずつの積の符号を見ると、xとyが同じ方向にずれているか逆方向にずれているかが分かる。

S(xy)だけでは「強さ」を測れない: S(xy)の値はxとyの単位(例: mmかmか)に依存してしまう。xの単位をmmからmに変えるとxの偏差が1000分の1になり、S(xy)も1000分の1になってしまう — 関係の強さ自体は何も変わっていないのに。この「単位に振り回される問題」を解決するのが分母の役割になる。
②

分母√(S(xx)·S(yy))は「残差平方和が0以上」から出てくる

回帰直線をあてはめるとき、傾きをある値tと仮定して yi−ȳ ≒ t(xi−x̄) で近似したときの残差平方和を考える。これは実測値と近似値のズレの2乗和なので、tがどんな値でも絶対に0以上になる。

傾きtを仮定したときの残差平方和 Se(t) = Σ{(yi−ȳ) − t(xi−x̄)}²　… 2乗の和なので常に Se(t) ≥ 0 展開すると: Se(t) = S(yy) − 2t・S(xy) + t²・S(xx)
Se(t)を最小にするtを求める(tについての下に凸な放物線の頂点) dSe/dt = −2S(xy) + 2t・S(xx) = 0 　→　 t* = S(xy) / S(xx) これは実は回帰係数β̂1そのもの — 「残差平方和を最小にする傾き」が最小二乗法の正体
最小値を代入し、Se(t*) ≥ 0 という条件を使う Se(t*) = S(yy) − S(xy)²/S(xx)　　これが0以上でなければならない S(yy) − S(xy)²/S(xx) ≥ 0　→　S(xy)² ≤ S(xx)・S(yy) 両辺のルートを取ると |S(xy)| ≤ √(S(xx)・S(yy))
これが分母の正体: S(xy)を√(S(xx)·S(yy))で割った値の絶対値は、上の不等式より必ず1以下になる。つまり相関係数の分母は「Sxyがどんなデータでも−1〜1に収まるように選ばれた、唯一自然な基準値」であり、天下り的に決められた式ではない。「残差平方和は2乗の和だから0以上」という、単回帰の平方和の分解(S(yy)=S(残差)+S(回帰による))で使った事実と全く同じものが、ここでも相関係数の上限を保証している。
③

幾何的に見ると「ベクトルのなす角のコサイン」

偏差の並び u=(x1−x̄, …, xn−x̄) と v=(y1−ȳ, …, yn−ȳ) を、n次元空間の2本のベクトルとみなす。すると S(xy)=u·v(内積)、S(xx)=|u|²、S(yy)=|v|² になるので、相関係数はちょうど2つのベクトルがなす角θのコサインと一致する。

r = S(xy) / √(S(xx)·S(yy)) = (u・v) / (|u||v|) = cos θ
④

第35回問3の数値で確かめる

与えられた S(xx)=265.73、S(yy)=14.27、S(xy)=58.13 を②の式にそのまま当てはめて、r=0.944という値の中身を分解する。

残差平方和と回帰による平方和(元の資料STEP4の数値版) S(回帰) = S(xy)²/S(xx) = 58.13² / 265.73 = 3379.1 / 265.73 ≒ 12.72 S(残差) = S(yy) − S(回帰) = 14.27 − 12.72 ≒ 1.55　( ≥ 0 を確認できる)
相関係数の2乗(寄与率) r² = S(xy)² / (S(xx)・S(yy)) = 3379.1 / (265.73×14.27) = 3379.1 / 3791.97 ≒ 0.891 r² = S(回帰)/S(yy) = 12.72/14.27 ≒ 0.891 (同じ値になる — r²は「全変動のうち回帰で説明できた割合」) r = √0.891 ≒ 0.944
元の資料の選択肢エ(0.891)の正体がここで分かる: 0.891はr²(寄与率)であり、rそのものではない。今回の計算でS(回帰)とS(yy)の比としても同じ0.891が出てくることから、「r²=寄与率」という関係が単なる暗記事項ではなく、②で示した同じ不等式から自然に出てくる値であることが確認できる。
角度に直すと θ = arccos(0.944) ≒ 19.3°

2本の偏差ベクトルのなす角はわずか19度ほどで、ほぼ同じ方向を向いている — これがr=0.944という「強い正の相関」の幾何的な意味になる。

⑤

なぜ相関係数rと回帰係数β1は式が似ているのに値が違うのか

②で求めた t* = S(xy)/S(xx) は回帰係数β̂1そのものだった。rとβ̂1の関係を整理すると、両者が一致するのは特別な場合だけだと分かる。

rとβ̂1の関係 β̂1 = S(xy)/S(xx)　、　r = S(xy)/√(S(xx)・S(yy)) 両辺を比較すると: r = β̂1 × √(S(xx)/S(yy)) = β̂1 × (S(x)/S(y))　　(S(x)=√S(xx), S(y)=√S(yy) はx,yの散らばりの大きさ)
第35回問3の数値で検算
量値意味
S(x) = √S(xx)√265.73 ≒ 16.30xの散らばりの大きさ
S(y) = √S(yy)√14.27 ≒ 3.78yの散らばりの大きさ
S(x)/S(y)≒ 4.31xの方がyよりずっと広く散らばっている
β̂1 × (S(x)/S(y))0.219 × 4.31 ≒ 0.944= r と一致
「ア.0.219」がなぜ相関係数の罠になるか、これで説明がつく: β̂1とrが同じ値になるのはS(x)=S(y)(xとyの散らばりの大きさが等しい)ときだけ。今回はxの散らばり(16.30)がyの散らばり(3.78)よりずっと大きいため、β̂1(0.219)はrよりも4倍以上小さい別の値になっている。式が似ているのは偶然ではなく②で見た同じt*が共通の起点になっているからだが、rは向きを揃えたうえで単位を消した「純粋な強さ」、β̂1は単位付きの「傾き」という別の量である。
要点

この解説から持ち帰ること

1分子S(xy)は、xとyが同じ方向に動いたか逆方向に動いたかを1点ずつの積の符号で数え、足し合わせたもの。
2分母√(S(xx)·S(yy))は天下り的な式ではなく、残差平方和Se(t)=S(yy)−2tS(xy)+t²S(xx)が常に0以上という事実から導かれる、Sxyの自然な上限。
3相関係数は幾何的には2本の偏差ベクトルがなす角のコサイン。−1〜1に収まるのはコサインの性質そのもの。
4r² = S(回帰による)/S(yy) = 寄与率。これも②の同じ不等式の言い換えにすぎない。
5回帰係数β̂1とrは同じt*=S(xy)/S(xx)から出発するが、β̂1は単位付きの傾き、rはxとyの散らばりの比で正規化した無単位の強さ。S(x)=S(y)のときだけ一致する。
