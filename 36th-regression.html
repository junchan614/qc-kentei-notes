平方和の分解から回帰係数・分散分析表まで

①はS(T)=Σ(yi−ȳ)²を「残差」と「回帰による平方和」に分解する式の用語と、その2つを図でどう見分けるかを問う知識問題。②は与えられる5つの和だけから3つの平方和を作れば、回帰係数も分散分析表もすべて機械的に埋まる計算問題。設問(23)〜(30)を順に解きながら、誤答選択肢が何の計算ミス・読み違えに対応しているかまで確認する。

①

平方和の分解 — 残差と回帰による平方和の見分け方 (23)〜(25)

単回帰分析では、データの構造式を yi = β0 + β1xi + εi とし、実測値yiと予測値ŷiの差の2乗和が最小になるようβ0・β1を求める(最小二乗法)。この式に意味があるかを分散分析で調べるために、yの平方和を次のように分解する。

平方和の分解 Σ(yi−ȳ)² = Σ(yi−ŷi+ŷi−ȳ)² 　　　　　　= Σei² + Σ(ŷi−ȳ)²

右辺第1項Σei²は、実測値yiと予測値ŷiの差(ei=yi−ŷi)の2乗和。この「実測−予測」の差を指す言葉が(23)。

②

回帰係数と分散分析表 — (26)〜(30)

溶接部品の特性値yと成分量xの関係を調べるため、n=20組のデータから次の値を得た。

n = 20 組のデータについて、次の値が得られている。
Σxi = 250 Σyi = 1379 Σxi² = 3370 Σyi² = 95299 Σxiyi = 17031
これに y = β0 + β1x を最小二乗法であてはめ、次を求める。
(26) β0 (27) β1 (28) 残差の自由度 (29) 分散比 F0 (30) 帰無仮説 H0
STEP 1

3つの平方和を求める

平方和はどれも「2乗の和 − 補正項(和の2乗をnで割ったもの)」の形。この形さえ覚えていれば3本とも同じ手順で書ける。

xの平方和 Sxx = Σx² − (Σx)²/n = 3370 − 250²/20 = 3370 − 3125 Sxx = 245
xとyの積和 Sxy = Σxy − (Σx)(Σy)/n = 17031 − (250 × 1379)/20 = 17031 − 17237.5 Sxy = −206.5
yの平方和（＝全体の変動 ST） Syy = Σy² − (Σy)²/n = 95299 − 1379²/20 = 95299 − 95082.05 Syy = 216.95
ここで平均も出しておく: x̄ = 250/20 = 12.5、ȳ = 1379/20 = 68.95。次のステップですぐ使う。
STEP 2

回帰係数を求める — (26)(27)

傾き β1 を先に出し、それを使って切片 β0 を出す。順序は必ず β1 → β0。

傾き（回帰係数） β1 = Sxy / Sxx = −206.5 / 245 = −0.84285… β1 ≒ −0.843
切片 β0 = ȳ − β1x̄ = 68.95 − (−0.843 × 12.5) = 68.95 + 10.5375 β0 ≒ 79.488
(26) β0 = 79.488 (27) β1 = −0.843
丸めの注意: β1 を丸めずに計算すると β0 = 79.4857 となり、選択肢の 79.488 とわずかにずれる。この問題は β1 を −0.843 に丸めてから代入すると選択肢とぴったり一致する。選択肢が僅差で並んでいるときは、丸めた値を代入して照合する。
STEP 3

分散分析表を埋める — (28)(29)

回帰の平方和は SR = Sxy² / Sxx で一発で出る(β1 × Sxy でも同じ)。あとは引き算と割り算だけ。

STEP 4

帰無仮説を答える — (30)

回帰の分散分析が検定しているのは「xでyを説明できるか」。説明できないとは、傾きがゼロで直線が水平になること。したがって帰無仮説は傾きに関する主張になる。

(30) H0 : β1 = 0
✓β1 = 0 … 傾きがゼロ＝xが変わってもyの予測値が変わらない。「回帰式に意味がない」という主張そのもの。これが正解。
✕β0 = 0 … 切片がゼロ、つまり直線が原点を通るかどうかの話。回帰式に意味があるかとは無関係。
✕ρ = 0 … 母相関係数の検定の帰無仮説。単回帰では結論が一致するが、分散分析表が検定しているのは回帰係数であり、設問が問う仮説はこちらではない。
判定: F0 = 73.0 に対し、F(1, 18; 0.01) ≒ 8.3。73.0 は 1%点をはるかに超えるので高度に有意となり、問題文の「回帰式に意味があるといえる」に一致する。
分析

誤答選択肢は何のミスに対応しているか

この問題の選択肢は、典型的な計算ミスをそのまま数値化して並べてある。自分が出した答えが下の「誤答」欄にあったら、右の原因を疑うとすぐ立て直せる。

選択肢と、その裏にある計算ミス
β1β0判定原因
−0.84379.488 正解 β1 = Sxy/Sxx、β0 = ȳ − β1x̄
−0.95280.850 誤 xとyを取り違えた。Sxy/Syy で割っている（yに対するxの回帰）
−1.18683.775 誤 分母に Sxx ではなく回帰平方和 SR(=174.05)を使ってしまった
0.88657.875 誤 符号ミス。Sxy が負であることを見落とし、β1 を正として ȳ − β1x̄ を計算した
β1 と β0 はペアで用意されている: 上表の通り、誤った β1 にはそれに対応する誤った β0 が必ず選択肢に置かれている。「β0 の選択肢に自分の答えがあったから合っている」とは限らない。検算は選択肢ではなく Sxy の符号と分母で行う。
要点

この問題から持ち帰ること

0残差=点と線の距離、回帰による平方和=線と平均線の距離。 矢印がデータ点に触れているかどうかで図を見分ける。
1平方和はすべて 「2乗の和 − 補正項」。Sxx・Sxy・Syy の3本を最初に出し切ってから設問に入る。
2Sxy の符号がそのまま β1 の符号になる。今回のように負であれば「xが増えるとyは減る」関係。ここを落とすと連鎖的に全問外す。
3単回帰の自由度は 回帰1・残差 n−2・計 n−1。n=20 なら 1・18・19。この3つは足し算で必ず整合する。
4回帰平方和は SR = Sxy² / Sxx で直接出せる。残差は引き算(Se = Syy − SR)。
5回帰の分散分析の帰無仮説は必ず H0: β1 = 0(傾きがゼロ)。切片や相関係数ではない。
6参考: 寄与率 R² = SR/ST = 174.05/216.95 = 0.802。yのばらつきの約80%をxで説明できている。
