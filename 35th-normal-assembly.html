QC検定2級 過去問解説 / 第35回 問2

規格外れ確率の計算と、部品を組み合わせたときの分散

前半は標準正規分布への変換だけの基本問題。後半の(7)〜(9)は同じ一般公式 V[z]=σx²+σy²+2cov(x,y) の使い分けを問うており、「意図的に大小を逆に組み合わせる」か「ランダムに組み合わせる」かで、共分散の項が残るか消えるかだけが変わる。

①

材料強度の規格外れ確率 — (5)(6)

ある加工品の材料強度(規格上限なし、規格下限80)は、平均86、分散3²の正規分布に従う。規格外れが発生する確率、およびそれを0.3%にするために必要な標準偏差を求める。

標準化して規格外れ確率を求める Z = (S(L) − μ) / σ = (80 − 86) / 3 = −2 P(X < 80) = P(Z < −2) = 0.0228　(正規分布表)
(5) ア. 0.0228
規格外れ確率を0.3%にする標準偏差 片側の裾確率0.3%に対応するzは、正規分布表からz=2.75 (86 − 80) / σ = 2.75 → σ = 6 / 2.75 σ ≒ 2.182
(6) カ. 2.182

②

部品A・部品Bを組み合わせた製品Cの分散 — (7)(8)(9)

部品Aの寸法xは平均μx・分散σx²、部品Bの寸法yは平均μy・分散σy²の正規分布に従う。製品Cの寸法はz=x+y。組み合わせ方によって、zの分散がどう変わるかを3パターンで問う。

a) 平均は組み合わせ方によらず常に成り立つ E[z] = E[x+y] = E[x] + E[y] μz = μx + μy
(7) ア. μx + μy
分散の一般式(xとyが独立とは限らない場合) V[z] = V[x+y] = V[x] + V[y] + 2cov(x,y)
b) 意図的に大小を逆に組み合わせる → 独立ではない 寸法xの小さなAには寸法yの大きなBを、xの大きなAにはyの小さなBを組み合わせる。
これはxが大きいほどyが小さくなる負の相関を人為的に作っており、cov(x,y)は0にならない σz² = σx² + σy² + 2cov(x,y)
(8) ケ. σx² + σy² + 2cov(x,y)
cov(x,y)は具体的にマイナスの値になる: 共分散の定義は cov(x,y)=E[(x−μx)(y−μy)]。b)の組み合わせ方では、xが大きい(x−μx>0)ペアには必ずyが小さい(y−μy<0)ものが来る(逆も同様)ので、各ペアの(x−μx)(y−μy)は常に負になり、その平均であるcov(x,y)自体が負の値になる。式の「+2cov(x,y)」の「+」は(x+y)²の展開から来る係数であって符号の宣言ではなく、そこへ負の数を代入する形になる。結果としてσz²はσx²+σy²より小さくなる(裾の広がりが打ち消し合う)。「意図的に負の相関を作る」と「式にマイナス記号が現れる」は別物で、一般式の形はb)もc)も変えずに、cov(x,y)という値の方が0か負かで変わる、という点を押さえておく。
c) ランダムに組み合わせる → 独立 組み合わせ方に規則性がなければxとyは互いに独立となり、cov(x,y)=0 σz² = σx² + σy²
(9) オ. σx² + σy²
b)とc)は同じ一般式の特殊ケース
b) 意図的に逆に組合せc) ランダムに組合せ
xとyの関係独立でない(負の相関)独立
cov(x,y)≠ 0= 0
分散σx²+σy²+2cov(x,y)σx²+σy² (共分散項が消える)
c)の式にσx²+σy²+cov(x,y)(係数2が付かない選択肢ク)を選ばないこと: V[x+y]=V[x]+V[y]+2cov(x,y)の「2」は(x+y)²=x²+y²+2xyの展開から来る係数であり、独立でも独立でなくても一般式の形自体は変わらない。独立なときはcov(x,y)という値そのものが0になるのであって、係数2が消えるわけではない。
補足

第40回問3との関係

「和の分散が独立なら足し算になる」という基本は、別々の板から4枚選ぶか1枚を4等分するかで分散が4σt²と16σt²に分かれる第40回問3でも扱った。あちらは「独立な4個の和」と「同一の値の4倍」という独立 vs 完全に同じの対比だったのに対し、本問のb)は「独立ではないが同一でもない、意図的な負の相関」という中間のケースを扱っている点が違う。

まとめると: 独立(cov=0) → 完全に同じ(相関1、分散はn²倍) → 意図的な負の相関(cov<0、一般式のまま)という3つのパターンを、この2つの過去問で押さえられる。
要点

この問題から持ち帰ること

1平均の加法性 E[x+y]=E[x]+E[y] は、xとyが独立かどうかに関係なく常に成り立つ。
2分散の一般式は V[x+y]=σx²+σy²+2cov(x,y)。独立のときだけcov(x,y)=0になり、見慣れたσx²+σy²の形になる。
3「意図的に大小を逆に組み合わせる」ような操作は、独立性を壊して負の相関を作る典型例。式は簡単にならない。
4規格外れ確率の計算はZ=(規格値−μ)/σの標準化が基本。「求めたい確率」と「その補集合(1−確率)」を取り違えないこと。
