交互作用が有意でないとき、何を捨てて何を残すか

因子A(添加剤、2水準)と因子B(添加量、3水準)、繰返し2回の繰返しのある二元配置実験。交互作用A×Bを検定してから、有意でなければ誤差にプーリングし、最適条件の点推定と信頼区間まで求める、この分野の定番の流れを一通り扱う。

問題

与えられた条件

製品強度に対する因子A(添加剤、2水準)と因子B(添加量、3水準)の効果を調べるため、完全ランダムに繰返し2回の実験を行った(全N=12個のデータ)。個々のデータは伏せられ、水準の組み合わせ(セル)ごとの合計だけが与えられている。

表5.1 セルごとの合計（繰返し2回分の合計）
B1B2B3合計

合計T.1 = 26T.2 = 75T.3 = 52T = 153

あわせて Σx² = 2295、行合計の2乗和 ΣT(i.)² = 11817、列合計の2乗和 ΣT(.j)² = 9005、セル合計の2乗和 ΣT(ij)² = 4553 が与えられている。水準数a=2、b=3、繰返しr=2、N=abr=12。

(29)

データの構造式を選ぶ

繰返しのある二元配置では、交互作用(ab)ijを誤差eijkと切り離して推定できる。これは「繰返しがある」からこそ可能になる。

データの構造式 x(ijk) = μ + a(i) + b(j) + (ab)(ij) + e(ijk)
(29) エ
罠: 交互作用項(ab)ijを持たない x(ijk) = μ + a(i) + b(j) + e(ijk) の形は、繰返しのない二元配置のときの構造式。今回は繰返しr=2があるので、交互作用を別の項として分離できる形を選ぶ必要がある。
STEP 1

平方和を分解する — (30)(31)

修正項CTを引いてから、行・列・セルの順に平方和を求め、最後に引き算で交互作用と誤差の平方和を出す。

修正項と全体の変動 CT = T² / N = 153² / 12 = 23409 / 12 = 1950.75 S(T) = Σx² − CT = 2295 − 1950.75 S(T) = 344.25
要因Aと要因Bの平方和 S(A) = ΣT(i.)² / (br) − CT = 11817 / 6 − 1950.75 = 1969.50 − 1950.75 S(A) = 18.75 S(B) = ΣT(.j)² / (ar) − CT = 9005 / 4 − 1950.75 = 2251.25 − 1950.75 S(B) = 300.50
セル間の変動 → 交互作用の平方和 S(AB) = ΣT(ij)² / r − CT = 4553 / 2 − 1950.75 = 2276.50 − 1950.75 = 325.75 S(A×B) = S(AB) − S(A) − S(B) = 325.75 − 18.75 − 300.50 S(A×B) = 6.50
誤差の平方和（引き算で求める） S(E) = S(T) − S(AB) = 344.25 − 325.75 S(E) = 18.50
(30) カ. 6.50 (31) ク. 18.50
STEP 2

交互作用は有意か — (32)(33)

自由度は水準数だけで機械的に決まる: φ(A)=a−1=1、φ(B)=b−1=2、φ(A×B)=(a−1)(b−1)=2、φ(E)=ab(r−1)=6。検算: 1+2+2+6=11=φ(T)。

交互作用と誤差の平均平方 V(A×B) = S(A×B) / φ(A×B) = 6.50 / 2 = 3.25 V(E) = S(E) / φ(E) = 18.50 / 6 ≒ 3.083 F(0) = V(A×B) / V(E) = 3.25 / 3.083 F(0) ≒ 1.05

棄却域は R: F(0) ≧ F(φ(A×B), φ(E); 0.05) = F(2, 6; 0.05) = 5.14。F(0)=1.05はこれより小さいので、交互作用は有意でない。

(32) イ. 2 (33) エ. 6
交互作用が有意でない ＝ 効果がゼロという意味ではない: V(A×B)=3.25はV(E)=3.083とほぼ同じ大きさで、「誤差と区別がつかない変動」というだけ。効果が全く無いとまでは言い切れないが、少なくとも「AとBの効果が互いの水準によって大きく変わる」とは言えない、という判断になる。
STEP 3

誤差にプーリングして、AとBを検定し直す

交互作用が有意でないので、A×Bの変動を誤差にプールし、より自由度の大きい誤差でAとBを検定し直す。

プーリング後の誤差 S(E') = S(E) + S(A×B) = 18.50 + 6.50 = 25.00 φ(E') = φ(E) + φ(A×B) = 6 + 2 = 8 V(E') = S(E') / φ(E') = 25.00 / 8 = 3.125
AとBを改めて検定する V(A) = S(A)/φ(A) = 18.75/1 = 18.75　→　F(0)_A = 18.75 / 3.125 = 6.00 V(B) = S(B)/φ(B) = 300.50/2 = 150.25　→　F(0)_B = 150.25 / 3.125 ≒ 48.1

F(0)_A=6.00 ＞ F(1,8;0.05)=5.32、F(0)_B≒48.1 ＞ F(2,8;0.05)=4.46。AもBもどちらも有意水準5%で有意になる。

STEP 4

最適条件と点推定 — (34)(35)

AもBも有意なので、それぞれ良いほうの水準を選んで組み合わせる。交互作用は誤差にプールした(＝無視できる)前提なので、点推定は「行の効果＋列の効果−全体平均」の加法モデルで求める。

水準ごとの平均 x̄(A1) = T(1.)/6 = 84/6 = 14.00　　x̄(A2) = T(2.)/6 = 69/6 = 11.50　→　A1が良い x̄(B1) = T(.1)/4 = 6.50　　x̄(B2) = T(.2)/4 = 18.75　　x̄(B3) = T(.3)/4 = 13.00　→　B2が良い 全体平均 x̄ = T/N = 153/12 = 12.75
(34) イ. A1B2
最適条件A1B2での点推定値 μ̂(A1B2) = x̄(A1) + x̄(B2) − x̄ = 14.00 + 18.75 − 12.75 μ̂(A1B2) = 20.00
(35) オ. 20.00
罠1: セル平均19.00をそのまま使ってしまう。 A1B2セルの実測平均は 38(セル合計)÷2(繰返し) = 19.00。これは「交互作用も込みの、そのセルだけの実測値」であり、交互作用を誤差にプールした(＝A×Bの効果は無視する)今回のモデルでは使わない。プーリング後は加法モデル x̄(A1)+x̄(B2)−x̄ = 20.00 が正しい点推定値になる。19.00は一見もっともらしいが、「プーリングした意味」を無視した値になってしまう。
罠2: 水準を取り違える。 A1ではなくA2を使うと 11.50+18.75−12.75=17.50 になる。A1・A2のどちらが「良い水準」かは平均の大小(14.00 ＞ 11.50)で決まるので、水準を取り違えるとそのまま別の数値に落ちてしまう。
STEP 5

信頼区間を求める — (36)

最適条件の母平均を区間推定するには、有効反復数neが必要になる。伊奈の式で求める。

有効反復数 n(e)（伊奈の式） n(e) = N / (1 + φ(A) + φ(B)) = 12 / (1 + 1 + 2) = 12 / 4 n(e) = 3 検算（田中の式）: 1/n(e) = 1/6 + 1/4 − 1/12 = 2/12 + 3/12 − 1/12 = 4/12 = 1/3　→　n(e)=3（一致）
母平均の信頼区間 μ̂(A1B2) ± t(φ(E'); 0.05)・√(V(E')/n(e)) = 20.00 ± 2.306 × √(3.125/3) = 20.00 ± 2.306 × 1.021 = 20.00 ± 2.353 下限 = 17.65　　上限 = 22.35
(36) キ. 22.35（上限）
罠3: 上限と下限を取り違える。 選択肢には下限17.65もそのまま並んでいる。「求めよ」と言われているのが上限なのか下限なのかを見落とすと、計算は合っているのに符号だけ逆の値を選んでしまう。μ̂±(誤差)のどちら側を聞かれているかを最後にもう一度確認する。
罠

(30)〜(33)の選択肢に紛れる「別の場所の値」

値判定どこから来るか
6.50正解 (30)S(A×B) = S(AB) − S(A) − S(B)
18.50正解 (31)S(E) = S(T) − S(AB)
3.25誤V(A×B)そのもの。平方和(30)を求める欄に平均平方の値を置いてしまう取り違え

選択肢の多くが「表の別の行・別の段階の本物の値」: 3.25(平均平方)・12.75(全体平均)・1(Aの自由度)・4(Bの分母)は、すべてこの問題のどこかで実際に登場する数字。今どの行(A・B・A×B・E)の、どの列(S・φ)を埋めているかを都度確認しないと、正しい計算をしていても違う欄の値を書いてしまう。
要点

この問題から持ち帰ること

1繰返しのある二元配置は行→列→セル→(引き算で)交互作用と誤差の順に平方和を求める。S(A×B)=S(AB)−S(A)−S(B)、S(E)=S(T)−S(AB)。
2交互作用が有意でなければ誤差にプーリングする: S(E')=S(E)+S(A×B)、φ(E')=φ(E)+φ(A×B)。プーリング後の誤差でAとBを検定し直す。
3プーリング後の最適条件の点推定は加法モデル μ̂=x̄(行)+x̄(列)−x̄(全体)。セルの実測平均(交互作用込み)とは別の値になる。
4有効反復数は伊奈の式 n(e)=N/(1+φ(A)+φ(B))(直交表のときはこちらが速い)。田中(田口)の式 1/n(e)=Σ(1/水準あたりの反復数)−(k−1)/N でも同じ値になる(kは加える要因の数)。
5信頼区間はμ̂±t(φ(E');0.05)√(V(E')/n(e))。上限と下限、そしてセル平均との3つを混同しないことがこの問題の最大のポイント。
