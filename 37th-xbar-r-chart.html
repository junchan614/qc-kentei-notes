X̄-R管理図の管理線を計算する

前半は「管理限界はなぜ ±3σ/√n の式から A₂R̄ の形に化けるのか」という公式の成り立ちを問う理論パート、後半は係数表を当てはめるだけの数値計算パート。理論を丸暗記していなくても、係数表の使い方さえ分かれば後半の(17)〜(21)は確実に得点できる構成になっている。

問題

設定

① 管理図は工程の統計的管理状態(安定状態)を確保・維持するために使う。中心線とその上下の一対の管理限界線を合わせて何と呼ぶか、また3シグマ法による管理限界の式がどう変形されてA₂という係数に行き着くかが問われる。

② ある機械部品の製造工程で、外形寸法を用いた解析用のX̄-R管理図を作成する。1日を群として1日5個のデータを採取し、20日分のデータを収集した。

群の大きさ n = 5 群の数 k = 20 ΣX̄ = 1182.2 ΣR = 210

STEP 1

(14) 中心線と管理限界線をまとめて呼ぶ名前

管理図の「打点する特性の平均的水準を表す中心線」と「その上下に管理外れを判定するための一対の管理限界線」。この2つをまとめて呼ぶ言葉が問われている。

(14) イ. 管理線
用語の整理: 「異常線」「安定線」「合計線」はいずれも管理図の用語としては存在しない紛らわしい選択肢。「3シグマ線」は限界の引き方(3σ法)を指す言葉であって、CL・UCL・LCLをまとめた総称ではない点に注意。
STEP 2

(15)(16) 3σ法の式がA₂R̄に化けるまで

k個の群がすべて同じ正規分布N(μ,σ²)に従うと仮定すると、3シグマ法による管理限界は μ±3σ/√n。ここでμ・σはともに未知なので、標本から推定した値に置き換えていく。

① μの推定値 k個の群平均 x̄ᵢ の平均 X̄̄ = Σx̄ᵢ/k で μ を推定する ② σの推定値 k個のRの平均 R̄ を使い、σ ≒ R̄/d₂ で推定する ③ ①②を3σ法の式に代入 μ ± 3σ/√n　=　X̄̄ ± 3(R̄/d₂)/√n　=　X̄̄ ± (15) ④ R̄以外をひとまとめにしてA₂と定義する A₂ = (16) とおくと UCL = X̄̄ + A₂R̄、LCL = X̄̄ − A₂R̄
(15)(16)の中身 (15) = 3R̄ / (d₂√n)　　… A₂R̄ と同じ値になる項 (16) = A₂ = 3 / (d₂√n)
この式変形そのものは管理図の係数の正体で1段ずつ図解済み。「3σ法の3」「Rからσへの換算(d₂)」「標本平均のばらつき(√n)」という3部品がA₂の中身であることが分かれば、(15)(16)は暗記ではなく組み立てで答えられる。
選択肢の文字について: 元画像では(15)(16)の選択肢の文字が判読できなかったため式のみで収録していたが、基準解答で確認できた記号は(15)=オ、(16)=ウ。手元の問題冊子で確かめる際は、上の3ステップの式とA₂=3/(d₂√n)という結論が一致する選択肢を選べばよい。数値としてのA₂は次のSTEP3でも n=5 の場合として実際に使う。
STEP 3

(17)〜(21) 管理線の計算

係数表はn(群の大きさ)の行を見る。今回はn=5なので A₂=0.577、D₄=2.114(D₃はn≦6のため考えない)。

a) X̄管理図の中心線 CL X̄̄ = ΣX̄ / k = 1182.2 / 20 CL(X̄) = 59.11
(17) 59.11
b) R管理図の中心線 CL(先に求めておくと(18)(19)の計算に使える) R̄ = ΣR / k = 210 / 20 CL(R) = 10.50
(20) 10.50
X̄管理図の UCL・LCL UCL/LCL = X̄̄ ± A₂R̄ = 59.11 ± 0.577 × 10.50 = 59.11 ± 6.0585 UCL = 59.11 + 6.0585 = 65.1685 ≒ 65.17 LCL = 59.11 − 6.0585 = 53.0515 ≒ 53.05
(18) UCL 65.17 (19) LCL 53.05
R管理図の UCL UCL = D₄R̄ = 2.114 × 10.50 = 22.197 ≒ 22.2 LCL = D₃R̄ … n=5 ≤ 6 のためLCLは考えない
(21) UCL 22.2
要点

この問題から持ち帰ること

1中心線+管理限界線をまとめて「管理線」と呼ぶ。異常線・安定線・合計線は存在しない紛らわしい選択肢。
2A₂という係数は「3σ法の3」「Rからσへの換算(÷d₂)」「標本平均のばらつき(÷√n)」の3つを1つにまとめただけ。A₂=3/(d₂√n) という中身を知っていれば(15)(16)は導出できる。
3ΣX̄=1182.2・ΣR=210は20群それぞれの平均・範囲の合計。全データ100個の合計ではない。÷kで割ることを忘れない。
4X̄管理図はA₂、R管理図はD₃・D₄と使う係数が別。掛ける相手はどちらもR̄であって、σそのものではない。
5n=5は6以下なのでR管理図のLCLは考えない(D₃が負になるため)。空欄のままにする=解答漏れではなく正しい判断。
