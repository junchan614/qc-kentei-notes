母平均の差を片側検定するのに、なぜt表は0.10で引くのか

2つのラインの特性値を比べるとき、まず等分散かどうかをF検定で確認し、その結果によって「併合分散を使う通常のt検定」と「Welchの検定」のどちらを使うかが分かれる。この問題ではその一連の流れを追いながら、片側検定なのに数値表を両側確率0.10の列で引くという、多くの受験者がつまずく箇所を重点的に扱う。

過去問そのものは掲載していません。お手元の問題冊子と合わせて読む前提です。

基準解答の公開前(2026年9月27日時点)に作成した暫定の解説です。基準解答と異なる場合は更新します。

問題

与えられた条件

ある製品の特性xについて、現行ラインAと改善を加えたラインBのデータを比較する。改善によってラインBはxがわずかに大きくなることが期待されている。

表3.1 2ラインのデータ
nΣxΣx²V(不偏分散)
ラインA(現行)832.4139.101.126
ラインB(改善)736.3192.71(13)

検定は2段階で行う。①まず両ラインの母分散が等しいとみなせるかをF検定で確認する。②その結果によって、平均の差の検定(片側検定、H1: μA<μB)で使う分散の求め方を決める。

STEP 1

ラインBの不偏分散を求める — (13)

平方和 S = Σx² − (Σx)²/n を求めてから、自由度 n−1 で割る。

ラインBの平方和・不偏分散 S_B = Σx² − (Σx)²/n = 192.71 − 36.3²/7 = 192.71 − 188.2414 S_B = 4.4686 V_B = S_B / (n_B−1) = 4.4686 / 6 V_B = 0.745
(13) イ. 0.745
選択肢の罠: 0.638 は S_B=4.4686 を自由度6ではなくサンプルサイズn_B=7で割った誤り(4.4686/7=0.638)。不偏分散は必ず「n−1」で割ることを確認する。
STEP 2

等分散の検定(F検定) — (14)(15)(16)

H0: σA²=σB²、H1: σA²≠σB²、有意水準α=0.05の両側検定。分散比の検定統計量F0は、必ず1以上になるよう、大きい方の不偏分散を分子に置く約束になっている。

検定統計量の作り方 V_A=1.126 > V_B=0.745 なので F0 = V_A / V_B 棄却域 R: F0 ≥ F(φ_A, φ_B; α/2) 分子の自由度 φ_A = n_A − 1 = 7、分母の自由度 φ_B = n_B − 1 = 6
(14) カ. 7 (15) オ. 6
F0の計算 F0 = V_A / V_B = 1.126 / 0.745 F0 = 1.51
(16) ウ. 1.51
F(7,6; 0.025)=5.70 なので、F0=1.51 < 5.70 となり棄却域に入らない(有意でない)。よって「母分散が等しい」という仮説は棄却されず、以降は等分散とみなして平均の差の検定を進める。
選択肢の罠: 1.76 は分子・分母の自由度や分散の組み合わせを変えた別の誤り。(14)(15)の選択肢に並ぶ 6・7・8・9 のうち、分子側にはn_A−1=7、分母側にはn_B−1=6を対応させる必要があり、AとBを取り違えると逆になる。
図解

等分散の検定から使う検定式への分岐

F検定の結果によって、続く平均の差の検定で使う分散の求め方が変わる。今回はF0=1.51が棄却域に入らなかったので、実際には左側の「併合分散を使うt検定」に進む。

STEP 3

片側検定でt表を引く確率 — (17)

H0: μA=μB、H1: μA<μB という片側検定、有意水準α=0.05。棄却域は R: t0 ≤ −t(φ; ?) の形になるが、この「?」に入れる確率をどう決めるかが最大の注意点である。

ここが最大のつまずきどころ: QC検定で配られる数値表(t表)は、両側確率Pで確率点を引く形式になっている。つまり表の列見出しは「両側にどれだけの確率を割り振るか」を意味する。片側検定で有意水準0.05にしたい場合、この片側0.05の面積は、両側だと合計0.10に相当する列を引けばよい。したがって片側α=0.05の片側検定であっても、表はt(13; 0.10)の列で引く。
(17) オ. 0.10
臨界値 φ = n_A + n_B − 2 = 8 + 7 − 2 = 13 t(13; 0.10) = 1.771　→　棄却域 R: t0 ≤ −1.771
選択肢の罠: 0.05をそのまま選ぶのは、「片側検定だから片側の確率0.05を表にもそのまま入れればよい」という誤解。0.025を選ぶのは、逆に「両側検定のときの片側面積(α/2=0.025)」の作り方と混同したもの。「検定が片側か両側か」と「表の確率が片側表記か両側表記か」は別の軸であり、この表は両側表記なので片側α=0.05には両側0.10の列を対応させる。
図解

片側検定の棄却域と、両側確率で引くt表の対応

STEP 4

検定統計量を計算する — (18)

等分散とみなせるので、2つのラインのデータを合わせた併合分散Vを使う。

併合分散 S_A = Σx² − (Σx)²/n = 139.10 − 32.4²/8 = 139.10 − 131.22 = 7.88 V = (S_A + S_B) / (n_A + n_B − 2) = (7.88 + 4.4686) / 13 V = 0.9499
検定統計量t0 x̄_A = 32.4/8 = 4.05　　x̄_B = 36.3/7 = 5.1857 t0 = (x̄_A − x̄_B) / √(V×(1/n_A + 1/n_B)) 　　= (4.05 − 5.1857) / √(0.9499×(1/8+1/7)) = −1.1357 / 0.5044 t0 ≒ −2.260
(18) ア. −2.260
−2.260 ≤ −1.771(STEP3の臨界値)なので有意と判定する。母平均の差の検定の結果、ラインBの改善効果があった(μA<μB)と結論できる。
選択肢の罠: −1.610 は、平方和や自由度の組み合わせを一部間違えたときに出やすい別の値。符号を正にしてしまう(+2.260)誤りにも注意。今回はH1: μA<μB なので、t0は必ず負の値になる。
STEP 5

等分散でない場合の検定 — (19)(20)

もしSTEP2のF検定で「等分散でない」と判定されていたら、STEP4のように単純な併合分散は使えない。その場合は次の手順を踏む。

等分散でない場合の手順 ① Satterthwaiteの式で (19) を計算する ② その (19) を自由度として使う (20) の検定を行う
(19) カ. 等価自由度 (20) ク. Welch
選択肢の罠: 語群には「Satterthwaite」自体も選択肢として含まれる。Satterthwaiteは等価自由度を計算する式の名前であり、検定そのものの名前ではない。「検定の名前」を聞かれている(20)にSatterthwaiteを選ぶと、Welchとの役割を取り違えたことになる。

要点

この問題から持ち帰ること

12つの母分散の比の検定では、F0が必ず1以上になるよう大きい方の不偏分散を分子に置く。
2等分散が棄却されなければ併合分散を使う通常のt検定、棄却されればSatterthwaiteの式で等価自由度を求めるWelchの検定に進む。
3t表が両側確率Pで引く形式の場合、片側検定の有意水準αは、両側確率2αの列で引く。片側0.05なら両側0.10の列。
4H1の不等号の向き(μA<μBかμA>μBか)によって、検定統計量t0の符号と棄却域の向き(左裾か右裾か)が決まる。
5「等価自由度を計算する式(Satterthwaite)」と「その自由度を使う検定(Welch)」は別物であり、名前を問われている対象を取り違えない。
