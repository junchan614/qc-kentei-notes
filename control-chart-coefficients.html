QC検定2級 / 管理図

管理図の係数の正体

A₂・d₂・D₃・D₄ は、暗記させるために置かれた謎の記号ではない。すべて「管理限界を ±3σ に引きたいのに σ がわからない」という一つの事情から出てくる。中身を開ければ、知っている式しか入っていない。

全体像

出発点

なぜ係数が必要になるのか

管理図の限界線は中心から ±3σ の位置に引く、と決まっている。ところが現場では母標準偏差 σ はわからない。そこで、計算が簡単な範囲 R（最大値 − 最小値）から σ を間接的に推定する。この橋渡しをするのが d₂ で、そこから A₂・D₃・D₄ が派生する。

やりたいこと 管理限界 = 中心線 ± 3 × （そこにプロットする値の標準偏差） 困っていること σ が未知。しかも毎回わざわざ標準偏差を計算するのは現場で手間 解決策 σ ≒ R̄ / d₂　（範囲の平均から σ を推定する）
d₂

範囲 R から σ を推定する

同じ工程からデータを取っても、1群に何個取るかで範囲 R の大きさは変わる。たくさん取るほど端の値を拾いやすく、R は広がる。だから「R が σ の何倍になるか」は n ごとに違い、その倍率が d₂ として表になっている。

A₂

A₂ は3つの部品でできている

X̄管理図の限界を、知っている式だけで組み立ててみる。途中で新しい概念は1つも出てこない。

① 管理限界は「プロットする値の ±3σ」 UCL / LCL = X̄̄ ± 3 × σ(x̄)　　※プロットするのは群の平均 x̄ ② 群平均のばらつきは σ/√n（標本平均の標準偏差） = X̄̄ ± 3 × σ / √n ③ σ がわからないので R̄/d₂ で置き換える = X̄̄ ± 3 × R̄ / (d₂ √n) ④ R̄ 以外をひとまとめにして A₂ と呼ぶ = X̄̄ ± A₂ R̄　　ただし A₂ = 3 / (d₂√n)
確認：n = 5 のとき（d₂ = 2.326） A₂ = 3 / (2.326 × √5) = 3 / (2.326 × 2.236) = 3 / 5.201 = 0.577　… 係数表の A₂ と一致する
D₃ D₄

R管理図の上下の限界

R管理図では範囲 R そのものをプロットする。中心線は R̄、限界は「R̄ ± 3 ×（R のばらつき）」。R のばらつきもまた σ に比例し、その倍率が d₃ という係数になる。

R管理図の限界 UCL = R̄ + 3 d₃ σ = R̄ + 3 d₃ (R̄/d₂) = R̄ (1 + 3d₃/d₂) = D₄ R̄ LCL = R̄ − 3 d₃ σ = R̄ (1 − 3d₃/d₂) = D₃ R̄

ここで問題が起きる。n が小さいと 3d₃/d₂ が 1 を超えてしまい、D₃ が負になる。範囲は絶対に負にならないので、負の下側限界には意味がない。だからn ≦ 6 では R管理図の LCL を引かない（表でも空欄や「—」になっている）。

注意

間違えやすいところ

1n は「群の大きさ」であって全データ数ではない。 5個ずつ25群なら、データは125個でも係数表は n = 5 の行を見る。ここを取り違えると係数が丸ごと変わる。
2A₂ に掛けるのは R̄ であって σ ではない。 A₂ の中にすでに「R から σ への換算」が組み込まれているので、σ を掛けると二重に換算してしまう。
3D₃・D₄ に掛けるのも R̄。 R管理図の限界は「R̄ の何倍か」で表される。足し算ではなく掛け算である点に注意（UCL = D₄R̄、R̄ + D₄ ではない）。
4n ≦ 6 で R管理図の LCL を書かない。 表が空欄なのは見落としではなく「考えない」という意味。無理に 0 と書く必要もない。
5X̄管理図と R管理図で使う係数が違う。 X̄図は A₂ のみ、R図は D₃ と D₄。d₂ は両者の裏側にいる係数で、単独で問題に出ることは少ない。
要点

持ち帰ること

1すべての係数は「±3σ を引きたいが σ が未知」という一つの事情から生まれている。σ の代役が R̄/d₂。
2A₂ = 3/(d₂√n)。「3σ法の3」「Rからσへの換算」「標本平均の√n」の3部品。σ/√n の資料がそのままここで効いてくる。
3D₄ = 1 + 3d₃/d₂、D₃ = 1 − 3d₃/d₂。D₃ が n ≦ 6 で負になるから LCL を考えない。
4係数表は群の大きさ n で行を選ぶ。値の暗記は不要だが、どの管理図でどの記号を使うかは覚えておく。
5n を大きくすると A₂ も D₄ も小さくなる ＝ 限界幅が狭まり異常を見つけやすくなる。係数の大小には意味がある。
