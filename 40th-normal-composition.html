QC検定2級 過去問解説 / 第40回 問3

4枚重ねると分散は4倍か16倍か — 独立に足すか、同じものを4倍するか

同じ「4枚重ねて厚さTにする」という作業でも、別々の素材板から4枚選ぶ(作り方1)のか1枚の板を4等分して重ねる(作り方2)のかで、Tが従う分布の分散が4σt²か16σt²かという4倍もの差になる。式の形はほぼ同じなのに答えが違う、正規分布の再生性でいちばん間違えやすいポイント。

問題

設定

素材板を4等分にカットし、4枚重ねて部品を製造する(図3.1)。素材板の厚みtは正規分布 N(μt, σt²) に従い、1枚の板内の厚みは均等(=同じ板からカットした4枚は全く同じ厚みt)とする。貼り合わせに使う接着剤の厚みは無視する。

STEP 1

作り方1: 別々の板からランダムに4枚選ぶ — (13)(14)

多数の素材板を4等分にカットしておき、その中からランダムに4枚を選んで貼り合わせる。選ばれる4枚は別々の素材板由来なので、それぞれの厚みt1, t2, t3, t4は互いに独立で、いずれもN(μt, σt²)に従う。

部品の厚さ T = t1 + t2 + t3 + t4 (独立な確率変数の和) 平均: E[T] = μt + μt + μt + μt = 4μt 分散: V[T] = σt² + σt² + σt² + σt² = 4σt²　(独立なので分散はそのまま足せる) T ~ N(4μt, 4σt²)
(13) ク. 4 (14) ク. 4
STEP 2

作り方2: 1枚の板を4等分して重ねる — (13)(15)

1枚の素材板を4等分にカットし、その4枚を使って貼り合わせる。「1枚の板内の厚みは均等」なので、この4枚の厚みはすべて同じ値t(同じ確率変数の実現値)。独立な4つの確率変数の和ではなく、1つの確率変数を4倍したものになる。

部品の厚さ T = t + t + t + t = 4t (同一の確率変数の定数倍) 平均: E[T] = E[4t] = 4μt　(ここは作り方1と同じ) 分散: V[T] = V[4t] = 4² × V[t] = 16σt²　(定数倍の分散は2乗で効く) T ~ N(4μt, 16σt²)
(13) ク. 4 (作り方1と共通の空欄) (15) コ. 16
空欄(13)が2回出てくる理由: 平均はどちらの作り方でも4μtで変わらないため、問題文はここでも同じ空欄番号(13)を使い回している。平均が同じだからこそ、分散だけが4倍と16倍で劇的に違うことが際立つ設問設計になっている。
補足

「独立に4つ足す」と「1つを4倍する」の違いを図で見る

V[X+Y]=V[X]+V[Y]が成り立つのはXとYが独立のときだけ。同じ確率変数を係数倍するV[aX]=a²V[X]とは根本的に別の計算であり、a個の独立な和とa倍の係数では分散の増え方が違う(和はa倍、係数倍はa²倍)。

「n個の独立な和」と「1個をn倍」の分散比較(一般形)
作り方1: 独立な和作り方2: 定数倍
式T = t1+t2+t3+t4T = 4t
各tiの関係互いに独立すべて同じ1つの値
平均4μt4μt (同じ)
分散4σt² (= n × σt²)16σt² (= n² × σt²)
標準偏差2σt (=√4 × σt)4σt (=4 × σt)
STEP 3

穴あけ加工後の厚みDの分布 — (16)(17)

作り方1で作った部品(T ~ N(4μt, 4σt²))の中央に円形の穴加工をする。穴の深さhはN(2.5μt, σh²)に従い、Tとは独立。底面から穴の底までの厚みDは、部品の厚さTから穴の深さhを引いたもの。

D = T − h (独立な2つの正規分布の差) 平均: E[D] = E[T] − E[h] = 4μt − 2.5μt = 1.5μt 分散: V[D] = V[T] + V[h] = 4σt² + σh²　(差でも独立なら分散は足し算)
数値を代入 (μt=2.0mm, σt=0.4mm, σh=0.6mm) E[D] = 1.5 × 2.0 = 3.0 V[D] = 4 × 0.4² + 0.6² = 4 × 0.16 + 0.36 = 0.64 + 0.36 D ~ N(3.0, 1.00)
(16) キ. 3.0 (17) エ. 1.0
「引き算」でも分散は引かない: D=T−hだからと分散もV[T]−V[h]としてしまう誤りが定番。TとHが独立なら、和でも差でも不確実性は積み上がる一方で、分散は必ず足し算になる。分散が負になることはあり得ないと考えれば、引き算がおかしいと気づける。
要点

この問題から持ち帰ること

1独立な確率変数の和 T=Σti は平均も分散もそのまま足し算: E[T]=Σμ, V[T]=Σσ²。
2同じ確率変数の定数倍 T=at は平均がa倍、分散はa²倍: E[T]=aμ, V[T]=a²σ²。「4枚重ねる」でも独立か同一かで分散の式が変わる。
3独立な正規分布どうしの和も差も正規分布になり(正規分布の再生性)、分散は符号によらず必ず足し算。
4問題文中で選択肢の空欄番号が使い回されることがある。数値が同じなら答えも同じになる設問設計だと気づけるかが鍵。
5実務的には「独立な複数ロットを混ぜる」方が「同一ロットを複製的に重ねる」よりばらつきが小さく抑えられる。式の違いはこの直感を裏付けている。
