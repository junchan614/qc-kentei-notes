2種類の「確率」を同じテーマで並べる — 古典的確率と統計的確率

10000枚の4桁カードを題材に、数え上げだけで厳密に決まる確率と、実際に試行して得られる確率を同時に求めさせる問題。2つの値はどちらも「確率」と呼ばれるが、性質がまったく違う。両者が一致しない理由まで理解して初めてこの問題が解けたことになる。

問題

確率の定義

0000から9999までの4桁の数字が1枚ずつ書かれた、合計10000枚のカードがある。この問題全体を通して使う定義はただ1つ。

確率の定義(ラプラスの古典的確率) P(A) = 条件Aを満たす場合の数 / 起こり得るすべての場合の数(N)
成立の条件: この定義が使えるのは「起こり得るすべての場合が同様に確からしい」とき、つまり10000枚のどのカードも等確率で引かれるときに限る。カードを1枚引く試行はまさにこの条件を満たすので、①②では数え上げるだけで確率が厳密に決まる。

①

奇数である確率 — (14)

10000枚のうち、奇数のカードと偶数のカードはちょうど5000枚ずつある(下1桁が1,3,5,7,9のものが奇数)。

計算 P(奇数) = 5000 / 10000 = 0.5
(14) オ. 5000/10000 = 0.5
この値は近似ではない: 5000枚と10000枚という数え上げから出てくる厳密に0.5という値。試行を1回もしていなくても、カードの構成さえわかれば正確に決まる。
②

月日として読み取れる確率 — (15)

4桁の数字を「上2桁=月、下2桁=日」として読んだとき、平年(365日)の実在する月日(0101〜1231)として成立する数字が何通りあるかを数える。0000〜9999のうち実在する月日として読める組み合わせは365通り(1月1日から12月31日まで、うるう日を除く)しかない。

計算 P(月日として読める) = 365 / 10000 = 0.0365
(15) イ. 365/10000 = 0.0365
①との共通点: ①も②も「全体の中で条件を満たすものが何通りあるか」を数え上げるだけで確率が決まっている。実際にカードを引く必要は一切ない。これが古典的確率(数学的確率)と呼ばれるゆえん。
③

実際に試行して求めた確率 — (16)

①②とは対照的に、③では実際にカードを引いて戻す試行を繰り返し、月日に合致した回数を数えている。

表3.1 試行の結果
試行回数(観測数)100回500回1000回10000回
1年間(平年)の月日に合致した回数4回18回37回362回
相対度数(合致した回数÷試行回数)0.04000.03600.03700.0362

一番多い試行回数(10000回)をとると、相対度数は…

計算 相対度数 = 362 / 10000 = 0.0362
(16) ア. 362/10000 = 0.0362
補足

0.0365と0.0362はなぜ完全には一致しないのか

②の0.0365は数え上げで決まる、揺らぎのない厳密値(古典的確率)。③の0.0362は実際に有限回試した結果としてたまたま得られた値(統計的確率、相対度数)。試行回数が増えるほど、統計的確率は古典的確率にだんだん近づいていく。

2つの確率の違いのまとめ:
古典的確率 と 統計的確率
古典的確率(数学的確率)統計的確率(経験的確率)
求め方場合の数を数え上げる実際に試行して相対度数をとる
試行の要否不要(理論だけで決まる)必要(データがないと求まらない)
値のブレない(常に同じ値)試行のたびに変わりうる
本問での値365/10000 = 0.0365362/10000 = 0.0362
問題文の一文が核心: 「これらの回数は『試行回数×(15)』とは完全には一致しないが、かなり近い数値となった」——これは統計的確率が古典的確率の近似になっていることを、まさにこの問題自身が言い当てている一文。①②(古典的確率)と③(統計的確率)を同じ土俵で並べて見せることが、この問題の設計意図そのもの。
要点

この問題から持ち帰ること

1確率の定義は P(A) = 条件を満たす場合の数 / すべての場合の数。「同様に確からしい」設定でのみ使える。
2古典的確率は数え上げだけで厳密に決まる値。試行しなくても求まる(①②)。
3統計的確率(相対度数)は実際に試行して初めて得られる、試行のたびにブレる値(③)。
4試行回数を増やすほど、統計的確率は古典的確率に近づく(大数の法則)。完全に一致しないズレそのものが「偶然によるばらつき」の証拠。
