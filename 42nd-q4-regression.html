相関係数から寄与率まで、ひとつの分散分析表でつながる

製品の質量xと熱処理時間yの関係を調べる単回帰分析。相関係数・回帰直線の傾きと切片・分散分析表・寄与率と、聞かれ方は多いが、元になる数字はSxx・Syy・Sxyの3つだけ。どの式にどの数字を代入するかを一直線に追っていく。

お断り: 過去問そのものは掲載していません。お手元の問題冊子と合わせて読む前提です。基準解答の公開前(2026-09-27時点)に作成した暫定の解説であり、基準解答と異なる場合は更新します。
問題

与えられた条件

製品の質量x(kg)と熱処理時間y(秒)について、20組(n=20)のデータから偏差平方和・偏差積和がすでに計算されて与えられている。

表4.1 データの要約（n=20）

STEP 1

相関係数を求める — (21)

相関係数rは、偏差積和Sxyを、SxxとSyyの積の平方根で割って求める。

相関係数 r r = S(xy) / √(S(xx)・S(yy)) = 274.64 / √(260.75 × 380.80) 　　= 274.64 / √99293.6 = 274.64 / 315.11 r ≒ 0.872
(21) エ. 0.872
xとyの間には強い正の相関がある(rが1に近い)。この0.872は、後で寄与率R²を求めるときにr²=0.760として検算に使える値でもある。
STEP 2

回帰直線を求める — (22)(23)

傾きβ̂1はSxy/Sxx、切片β̂0は「回帰直線は必ず(x̄,ȳ)を通る」性質からȳ−β̂1x̄で求める。

傾き β̂(1) β̂(1) = S(xy) / S(xx) = 274.64 / 260.75 β̂(1) ≒ 1.053
切片 β̂(0) β̂(0) = ȳ − β̂(1)・x̄ = 18.60 − 1.053 × 14.31 = 18.60 − 15.068 β̂(0) ≒ 3.532
(22) エ. 1.053 (23) キ. 3.532
丸め方に注意: β̂(1)=1.053(小数第3位までに丸めた値)を使って計算すると3.532になるが、丸める前の1.05329…をそのまま使うと3.527に近い値になる。選択肢と合わせるには「表示桁数まで丸めてから次の計算に進む」進め方が前提になっている。
STEP 3

分散分析表を作る — (24)(25)(26)

回帰による変動SRはSxy²/Sxxで最短に求まり、残差SeはSyyからの引き算。自由度はφR=1、φe=n−2=18。

回帰による変動 S(R) S(R) = S(xy)² / S(xx) = 274.64² / 260.75 = 75427.13 / 260.75 S(R) ≒ 289.27
残差の変動 S(e)（引き算で求める） S(e) = S(yy) − S(R) = 380.80 − 289.27 S(e) ≒ 91.53
平均平方と分散比F(0) φ(R) = 1、φ(e) = n − 2 = 20 − 2 = 18 V(e) = S(e) / φ(e) = 91.53 / 18 = 5.085 V(R) = S(R) / φ(R) = 289.27 / 1 = 289.27 F(0) = V(R) / V(e) = 289.27 / 5.09 F(0) ≒ 56.83

STEP 4

有意性を判定する — (27)

F(0)=56.83を、F(1,18;0.01)=8.29と比較する。分子の自由度1、分母の自由度18のF表を使う。

F(0)=56.83 ＞ F(1,18;0.01)=8.29 なので、帰無仮説H0: β1=0は有意水準1%で棄却される。質量xと熱処理時間yの間には直線的な関係があり、しかもその根拠は強い。

(27) イ. 高度に有意である
STEP 5

寄与率を求める — (28)

寄与率R²は、全体の変動のうちどれだけを回帰で説明できたかを表す割合で、SR/STで求める。相関係数rの2乗と一致することでも検算できる。

寄与率 R² R² = S(R) / S(T) = 289.27 / 380.80 R² ≒ 0.760 検算: r² = 0.872² = 0.760（一致）
(28) ア. 0.760
罠

選択肢に紛れる「別の割り算の答え」

この問題の選択肢には、正しい計算の途中で自由度や分母を1つ間違えると出てくる値が丁寧に用意されている。特に自由度の間違いはF(0)にも連鎖する。

(22)(23)(28)は共通の選択肢群から出題される: この3問と(21)は選択肢が重なっており、r=0.872やR²=0.760といった別の空欄の正解が、傾きや切片の選択肢としても並んでいる。数字自体は本物なので、「今どの量を求めているか」を指差し確認しないまま似た値を選ぶと、そのまま不正解になる。
要点

この問題から持ち帰ること

1相関係数・回帰係数・分散分析表・寄与率は、すべてS(xx)・S(yy)・S(xy)の3つの数字だけから計算できる。新しいデータは要らない。
2傾きβ̂(1)=S(xy)/S(xx)、切片β̂(0)=ȳ−β̂(1)x̄。分母分子を逆にすると1.460のような別の値になってしまう。
3S(R)=S(xy)²/S(xx)、S(e)=S(yy)−S(R)。分母をS(xx)とS(yy)で取り違えると198.08のような近い値が出るので要注意。
4残差の自由度はφ(e)=n−2。n−1(合計の自由度)やnそのもので割ると、V(e)だけでなくF(0)まで連鎖して誤る。
5寄与率R²=S(R)/S(T)は、相関係数の2乗r²と一致する。片方を求めたらもう片方で検算できる。
