QC検定2級 / 単回帰分析

回帰による変動 SR の求め方

SR は書き方が4通りあり、どれも同じ値になる。定義式のまま計算すると大変だが、回帰直線が必ず (x̄, ȳ) を通るという性質を使うと、与えられた統計量だけで一発で出せる形に変わる。その仕組みを追う。

問題

与えられているもの

30組のデータから、次の3つの統計量が計算されている。
Syy = 8842.67（総平方和） Sxx = 40.26（xの偏差平方和） Sxy = 541.00（偏差積和）
個々のデータ（x₁, y₁ …）は与えられていない。この3つだけで SR を出すのがこの設問の要求。
ここが出発点: 定義通りの SR = Σ(ŷᵢ − ȳ)² を計算するには、30個すべての予測値 ŷᵢ が必要になる。しかしデータは与えられていない。だから定義式は使えない — 別の形に書き換える必要がある、というのがこの問題の構造。
確認

SR は何を表す量か

yのばらつき全体（ST = Syy）は、回帰直線で説明できる分（SR）と説明できない残り（Se）に分かれる。SR は「xを知っていることで説明できたばらつきの量」。

ST = SR + Se　　（8842.67 = SR + Se）

この分解そのものについては単回帰分析の分散分析表で図解しているので、変動の分解が曖昧なら先にそちらを。ここではSR を実際にどう計算するかに絞る。

核心

なぜ SR = b² × Sxx になるのか

鍵になるのは、最小二乗法で引いた回帰直線は必ず点 (x̄, ȳ) を通るという性質。この1点から、予測値のズレと x のズレが単純な比例関係になる。

あとはこれを2乗して全部足すだけ。「c 倍したものの2乗和は c² 倍になる」という、なぜ√nで割るのかで扱ったのと同じ性質がここでも効く。

図の関係を2乗して合計する SR = Σ(ŷᵢ − ȳ)² 　 = Σ { b (xᵢ − x̄) }²　　… 図1の関係を代入 　 = b² Σ(xᵢ − x̄)²　　　　… b は定数なので外に出せる 　 = b² × Sxx
意味で読むと: Sxx は「x が持っているばらつきの量」。回帰直線はそれを b 倍に拡大して y のばらつきへ変換している。2乗の世界なので倍率は b² になる。SR とは「x のばらつきが、直線を通って y に伝わった量」ということ。
4つの顔

同じ SR が4通りに書ける

ここに b = Sxy / Sxx を代入していくと、次々と別の形になる。どれも同じ値なので、問題で与えられたものに合わせて選べばよい。

変換の中身（b = Sxy/Sxx を代入するだけ） b² × Sxx = (Sxy/Sxx)² × Sxx = Sxy² / Sxx b × Sxy = (Sxy/Sxx) × Sxy = Sxy² / Sxx
計算

実際に解く

まず傾き b を出し、続いて SR、そして残差平方和へ進む。

傾き b …(24) b = Sxy / Sxx = 541.00 / 40.26 ≒ 13.44
回帰による変動 SR …(25)　★3通りとも同じ値になる ① Sxy²/Sxx = 541.00² / 40.26 = 292681 / 40.26 = 7269.77 ② b × Sxy = 13.4377 × 541.00 = 7269.77 ③ b² × Sxx = 13.4377² × 40.26 = 180.57 × 40.26 = 7269.77 SR = 7269.77
残差平方和 Se …(26) Se = ST − SR = 8842.67 − 7269.77 = 1572.90
(24) b = 13.44 (25) SR = 7269.77 (26) Se = 1572.90
どの式を使うべきか: 与えられているのが Sxx と Sxy だけなら Sxy²/Sxx が最短。ただし今回のように b を先に問われている場合（(24)→(25)の順）は b × Sxy が速い。せっかく出した b を使い回せるうえ、掛け算1回で済む。

要点

持ち帰ること

1回帰直線は必ず (x̄, ȳ) を通る。 ここから ŷ − ȳ = b(x − x̄) が出て、SR の変形がすべて始まる。
2SR = b²·Sxx = b·Sxy = Sxy²/Sxx。 3つとも同じ値。b = Sxy/Sxx を代入して行き来しているだけ。
3データが与えられていない問題では定義式は使えない。 偏差平方和・偏差積和だけで解ける形（Sxy²/Sxx）に持ち込むのが定石。
4Se は引き算で出す。 Se = ST − SR。残差を1つずつ計算する必要はない。
5SR ≦ ST は必ず成り立つ。 超えたら計算ミス。比 SR/ST（寄与率）が0〜1に収まるかで検算できる。
6Sxy は負にもなるが、SR は必ず正。 2乗しているので符号は消える。傾きが負でも「説明できた量」は正の値。
