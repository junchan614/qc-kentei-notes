寄与率R²とSE(b)
概念の掘り下げ（第38回 問4 関連）

寄与率R²とSE(b)=√(Ve/Sxx) — 2つの式は何を測っているのか

「単回帰の分散分析表〜信頼区間」の(27)寄与率R²と(29)信頼区間で使うSE(b)=√(Ve/Sxx)は、どちらも計算のやり方は暗記できても「なぜその式になるか」は素通りしがちな2つの値。R²は「当てはまりの良さ」、SE(b)は「傾きの推定がどれだけブレるか」――別のことを測っている、という区別を軸に、式の由来を追う。

①

寄与率R² — 「全体の変動のうち何%を説明できたか」

単回帰では全体の変動S(yy)が、回帰で説明できる部分S(R)と、説明しきれない残差S(e)にきれいに分かれる。この事実(平方和の分解)がR²の定義そのもの。

平方和の分解（第38回 問4のデータ） S(yy) = S(R) + S(e) 19.07 = 15.23 + 3.84
寄与率R² の定義 R² = S(R) / S(yy) = 15.23 / 19.07 R² ≒ 0.7986

この式を1から引く形に書き換えると、R²の意味がもう一段はっきりする。

同じ式の言い換え R² = S(R)/S(yy) = (S(yy)−S(e))/S(yy) = 1 − S(e)/S(yy) 　= 1 − 3.84/19.07 = 1 − 0.2014 R² ≒ 0.7986（同じ値）
0≤R²≤1になる理由は暗記不要: S(e)は残差(実測−予測)を2乗して足した値なので、必ず0以上。そしてS(e)=S(yy)−S(R)という引き算の形から、S(e)がS(yy)を超えることもない。この2つだけから「R²=S(R)/S(yy)は0以上1以下」が自動的に出る。相関係数rの−1≤r≤1も同じ不等式の言い換えで、実はR²=r²という関係にある(相関係数はなぜこの式になるのかで導出済み)。
R²=0.7986の実感: 「濃度xのばらつきだけで、質量yのばらつきの約80%を説明できる」という意味。残り約20%は、このモデルに入っていない別の要因や測定誤差。R²は当てはめの良さを測る値であって、傾きbの大きさとは無関係――b自体がいくら大きくても、点が直線から大きく散らばっていればR²は小さくなる。
②

SE(b)=√(Ve/Sxx) — 「傾きbの推定はどれだけブレるか」

信頼区間の式 b ± t(n−2,0.025)×√(Ve/Sxx) の中で、√(Ve/Sxx)だけが回帰特有の部品。これは傾きbの標準誤差 SE(b)――「同じ実験をやり直したら、推定される傾きbはどれくらいの幅でブレるか」を表す。天下り的な式に見えるが、bの計算式を分散の目で見直すだけで出てくる。

出発点: bを「yの重み付き和」として書き直す b = S(xy)/S(xx) = Σ(xi−x̄)(yi−ȳ) / S(xx) 　Σ(xi−x̄)=0 なので Σ(xi−x̄)ȳ=0 → yiの前のȳは消せる b = Σ ci·yi 　（ここで ci = (xi−x̄)/S(xx) ）

つまりbは、n個のデータyiを「重みci」で足し合わせた値にすぎない。重みciはxiが平均から離れているほど大きい。分散は「独立な値の重み付き和」に対してΣ(重み²×分散)という決まった計算ができるので、あとは重みciの性質を2つ確認するだけでよい。

重みciの性質 Σci² = Σ(xi−x̄)² / S(xx)² = S(xx) / S(xx)² Σci² = 1/S(xx)
bの分散（yiは独立・分散σ²を仮定） Var(b) = Var(Σci·yi) = Σci²・Var(yi) = σ²・Σci² 　　　 = σ² × 1/S(xx) = σ²/S(xx) SD(b) = σ / √S(xx)
σ²は未知 → 残差の平均平方V(e)で置き換える σ²の不偏推定量が V(e)（分散分析表の残差の行） SE(b) = √( V(e) / S(xx) )
SE(b) = √(Ve/Sxx) の正体 = 「傾きbの標準偏差」の推定値
分母・分子の直感: S(xx)は「xをどれだけ広い範囲で測ったか」。広く測るほど直線の傾きが一意に決まりやすく、SE(b)は小さくなる。Veは「直線に対する点の散らばり(誤差)の大きさ」。散らばりが大きいほど傾きの推定は不安定になり、SE(b)は大きくなる。分母にSxx・分子にVeがあるのは、この2つの直感をそのまま数式にしたもの。

要点

この2つの式が答えている「別の問い」

1R² = S(R)/S(yy) は「直線がデータにどれだけ当てはまっているか」という当てはめの良さの指標。0〜1の値になるのは、S(e)≥0かつS(e)≤S(yy)という平方和の分解から自動的に出る。
2SE(b) = √(Ve/Sxx) は「傾きbの推定値がどれだけブレるか」という推定の精度の指標。b=Σci yi(ci=(xi−x̄)/Sxx)と書き直し、独立な値の重み付き和の分散Σci²Var(yi)を計算すると自然に出てくる。
3SE(b)の分母S(xx)は「xを広い範囲で測ったか」、分子Veは「点が直線からどれだけ散らばっているか」。広く測るほど、散らばりが小さいほど、傾きは精度よく推定できる。
4R²が高い(当てはまりが良い)ことと、SE(b)が小さい(傾きの推定が正確)ことは連動しやすいが同じ量ではない。R²はS(yy)に対する相対的な割合、SE(b)はS(xx)というxの散らばりに依存する絶対的な誤差の大きさ。
5「分散の性質(独立な値の和の分散=分散の和)だけから標準誤差を導く」考え方は、標本平均の標準偏差がσ/√nになる理由と全く同じ型。bはyの単純平均ではなく重み付き平均という違いがあるだけ。
関連

関連資料

単回帰の分散分析表〜信頼区間（第38回 問4）このR²とSE(b)が実際に問われた元の過去問。この資料はその(27)(29)を深掘りしたもの。 相関係数はなぜこの式になるのかR²=r²の関係と、0≤R²≤1が導かれる同じ不等式の由来をより深く扱う。 標本平均の標準偏差がσ/√nになる理由「独立な値の和の分散」からSE(b)と同じ導出パターンを先に扱っている基礎編。 自由度の正体SE(b)の計算で使うV(e)の自由度がn−2になる理由。
