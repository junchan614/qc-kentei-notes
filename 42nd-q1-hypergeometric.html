抜き取ったら戻さない — 超幾何分布の分散はなぜ二項分布より小さくなるのか

ロットの中から不適合品を非復元(抜き取ったものを戻さない)で抜き取るとき、サンプル中の不適合品数がしたがう確率分布が超幾何分布である。期待値の公式は二項分布と同じ形になるが、分散には「有限母集団修正」という項が掛かり、二項分布より必ず小さくなる。この問題では確率分布表の空欄を埋めながら、その構造を数値で確認する。

過去問そのものは掲載していません。お手元の問題冊子と合わせて読む前提です。

基準解答の公開前(2026年9月27日時点)に作成した暫定の解説です。基準解答と異なる場合は更新します。

問題

与えられた条件

ロットの大きさ N=18、そのうち不適合品 r=4。このロットからランダムに n=5 個を非復元で抜き取ったとき、サンプル中に含まれる不適合品の個数を x とする。x は超幾何分布にしたがう。

超幾何分布の確率関数 f(x) = C(r, x)・C(N−r, n−x) / C(N, n)　　(0 ≤ x ≤ t、t は n と r の小さいほう) N=18, r=4, n=5 なので t=4。 C(18,5) = 8568
表1.1 x の確率分布(空欄が(1)(2))
x012345合計
P(x)0.23370.46730.2549(1)(2)0.00001.0000

x=5(サンプル5個すべてが不適合品)は、そもそも不適合品が r=4 個しかロットにないので起こり得ず、P(5)=0.0000 になる。これは超幾何分布に特有の制約で、二項分布にはない。

STEP 1

確率の空欄を埋める — (1)(2)

公式にそのまま x=3, x=4 を代入する。C(4,3)=4、C(4,4)=1、C(14,2)=91、C(14,1)=14 を使う。

P(3) の計算 P(3) = C(4,3)・C(14,2) / C(18,5) = 4 × 91 / 8568 = 364 / 8568 P(3) = 0.0425
P(4) の計算 P(4) = C(4,4)・C(14,1) / C(18,5) = 1 × 14 / 8568 = 14 / 8568 P(4) = 0.0016
(1) イ. 0.0425 (2) ア. 0.0016
選択肢の罠: 0.0850 は 0.0425 を2倍した値、0.1275 は 0.0425 の3倍、0.1683 も同種の掛け違いで、いずれも期待値 E(x)=Σx・P(x) の計算で出てくる「x・P(x)」の項(3×0.0425=0.1275 など)を、P(x) そのものと取り違えたときに紛れ込みやすい値である。
STEP 2

期待値を求める — (3)

E(x) = Σ x・P(x) を x=0〜5 まで足し合わせる。x=0 の項は 0 なので省略できる。

E(x) の計算 E(x) = 1×0.4673 + 2×0.2549 + 3×0.0425 + 4×0.0016 + 5×0.0000 　　= 0.4673 + 0.5098 + 0.1275 + 0.0064 E(x) = 1.1110
(3) オ. 1.1110
公式での検算: 超幾何分布の期待値は E(x) = n・r/N という単純な形で求まる。E(x) = 5×4/18 = 20/18 = 1.1111 となり、表の積み上げ計算(1.1110)とほぼ一致する(差は丸め誤差)。この n・r/N は、二項分布 B(n,P) の期待値 nP において P=r/N と置いたものと同じ形である。
選択肢の罠: 0.7717・0.8813・0.9014・1.1011 が並ぶ。1.1011 は 1.1110 の桁を書き間違えたような値、他は Σx・P(x) の項を一部だけ数えたり、係数(x)を掛け忘れたりした場合に近い値になる。
STEP 3

分散を求める — (4)

分散は V(x) = E(x²) − {E(x)}² で求める。まず E(x²) = Σ x²・P(x) を計算する。

E(x²) の計算 E(x²) = 1²×0.4673 + 2²×0.2549 + 3²×0.0425 + 4²×0.0016 　　= 0.4673 + 1.0196 + 0.3825 + 0.0256 E(x²) = 1.8950
V(x) の計算 V(x) = E(x²) − {E(x)}² = 1.8950 − 1.1110² = 1.8950 − 1.2343 V(x) = 0.6607
(4) イ. 0.6607
公式での検算(有限母集団修正): 超幾何分布の分散は V(x) = n・p(1−p)・(N−n)/(N−1)、ただし p=r/N。ここで p=4/18=2/9 なので、n・p(1−p) = 5×(2/9)×(7/9) = 0.8642。これに (N−n)/(N−1) = 13/17 = 0.7647 を掛けると 0.6609 となり、積み上げ計算(0.6607)とほぼ一致する。この (N−n)/(N−1) が有限母集団修正項で、非復元抽出(抜き取ったら戻さない)であることの効果を表している。
選択肢の罠: 0.4358・0.8997・1.3353・1.8976 が並ぶ。1.8976 は E(x²)=1.8950 に近い値で、分散を求める際に {E(x)}² を引き忘れ、E(x²) をそのまま分散と取り違えたときに出てきやすい。
図解

超幾何分布と二項分布 — 平均は同じでも裾の広がりが違う

もし非復元ではなく復元抽出(毎回戻してから引く)だったなら、x は二項分布 B(5, 2/9) にしたがう。二項分布の期待値も n・p=5×2/9=1.111 で超幾何分布と全く同じになるが、分散は有限母集団修正がかからないぶん大きくなり、確率がより裾広がりに分布する。

N が大きいときは二項分布で近似できる: 有限母集団修正項 (N−n)/(N−1) は、N が n に比べて十分大きいと 1 に近づく。ロットが大きく、そこから抜き取る個数が少ない場合には超幾何分布は二項分布にほぼ一致する。今回のように N=18, n=5 のようにロットが小さいと、この修正の効果が数値にはっきり表れる。

要点

この問題から持ち帰ること

1超幾何分布は非復元抽出のときにサンプル中の不適合品数がしたがう分布。確率関数は f(x) = C(r,x)C(N−r,n−x)/C(N,n)。
2期待値は E(x) = n・r/N で、二項分布の nP と同じ形(p=r/N とみなせる)。
3分散は V(x) = n・p(1−p)・(N−n)/(N−1)。(N−n)/(N−1) が有限母集団修正で、これが超幾何分布と二項分布の違いの本体。修正項は必ず1以下なので、超幾何分布の分散は同じ n, p の二項分布より小さい。
4N が n に比べて十分大きければ (N−n)/(N−1)≒1 となり、超幾何分布は二項分布で近似できる。
5期待値・分散を確率分布表から積み上げ計算したら、必ず公式(n・r/N、有限修正つきの分散式)で検算する。両者が一致することで計算ミスに気づける。
