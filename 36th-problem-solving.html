層別で真因にたどり着く

不織布マスクの引張強度不足を追う問題解決事例。パレート図・ヒストグラム・工程能力指数・特性要因図・散布図と手法は次々変わるが、この問題を貫いているテーマはひとつ、「層別」。全体で見ていたものをラインA・Bに分けた瞬間に何が見えるかを、設問ごとに追いかける。

(39)(40)

工程能力指数を計算する

規格が下側だけ(SL=20)なので、両側規格の Cp ではなく片側規格の式を使う。平均から規格までの距離が、標準偏差3個分の何倍あるかを表す。

下側規格のみの場合の工程能力指数 Cpk = (x̄ − SL) / (3s)
ラインA（x̄ = 22.05、s = 0.363）…(39) = (22.05 − 20) / (3 × 0.363) = 2.05 / 1.089 Cpk ≒ 1.882
ラインB（x̄ = 21.40、s = 0.692）…(40) = (21.40 − 20) / (3 × 0.692) = 1.40 / 2.076 Cpk ≒ 0.674
(39) 1.882 (40) 0.674
公式が正しいかの確認: 図6.2に書かれた全体の値(x̄=21.73、s=0.638、C=0.90)を同じ式に入れると (21.73−20)/(3×0.638) = 0.904 となり、図の 0.90 と一致する。問題文中に検算材料が置かれているので、式の選択に迷ったらここで確かめられる。
工程能力指数の判定基準: Cpk ≧ 1.33 で十分、1.00 〜 1.33 はまずまず(要注意)、1.00 未満は不足。ラインA(1.88)は十分だが、ラインB(0.67)と全体(0.90)は明らかに不足している。この時点でラインBが問題の中心だと数値で確定する — (43)の答えはここで決まっている。

(43)

特性要因図の「特性」を決める

選択肢は「〜が多い」系と「〜をなくす」系、そして対象が「不織布マスク全体」「ラインA」「ラインB」で組み合わされている。2つの軸で消していくと1つに絞れる。

軸1特性は「結果・現象」であって「目標・対策」ではない。 特性要因図の背骨の先に書くのは、いま起きている悪さの姿。「〜をなくす」「〜を高める」は目標の表現なので、この時点ですべて消える。
軸2対象は層別で絞り込んだ結果を書く。 ①②の解析でラインB(57件、Cpk=0.674)に問題が集中していることが判明済み。全体やラインAを特性に据えると、せっかくの層別が無駄になる。
ア不織布マスクの生産性が低い → 対象が広すぎる。追っているのは引張強度不足
イ不織布マスクの生産性を高める → 目標の表現。特性ではない
ウ不織布マスクの製造不適合数が多い → 層別前の話に戻ってしまう
エ不織布マスクの製造不適合数をなくす → 目標の表現
オラインAの引張強度不適合数が多い → ラインAは Cpk=1.88 で問題なし
カラインBの引張強度不適合数が多い → 現象の表現＋層別で絞った対象。これが正解
キラインAの引張強度不適合数をなくす → 対象も表現も誤り
クラインBの引張強度不適合数をなくす → 対象は正しいが「なくす」は目標の表現
(43) カ
ここが引っかけどころ: 対象(ラインB)が合っている「ク」が用意されている。対象だけ合わせて選ぶと落ちるように作られているので、必ず「〜が多い(現象)」か「〜をなくす(目標)」かを最後に確認する。
(44)〜(47)

散布図で要因を検証する

電流値 x と引張強度 y の関係を、まず全体で見て、次にライン別に層別して見る。層別すると関係の強さが変わることが、この段落の主題。

アラインA,Bともに電流値xをコントロールすることで引張強度不足を改善できる → ラインBは相関が弱いので、xを操作してもyは思うように動かない
イ…ラインAよりラインBのほうが、電流値xをコントロールすることの効果が大きい → 逆。相関が強いラインAのほうがxで制御しやすい
ウ…ラインBにおいて電流値xをばらつかせている原因を究明することが必要である → ばらついているのはy(引張強度)であって x ではない。主語がすり替わっている
エ…ラインBにおいて電流値x以外で引張強度yをばらつかせている原因を究明することが必要である → 散布図から読み取れる事実と一致。これが正解
(47) エ
ウとエの差はたった数文字: 「xをばらつかせている原因」(ウ)と「x以外でyをばらつかせている原因」(エ)。散布図で縦に散っているのは y なので、探すべきはy を散らす x 以外の要因。長文選択肢では、何がばらついているのか(主語)に線を引いて読むと差が見える。
(44)(45)(46)について: これらの選択肢が載っている p.64 の該当箇所が判読できなかったため、記号の特定は保留とする。文脈上は「全体の散布図では2つのラインが混ざるため関係がはっきりせず、相関は弱い」という趣旨が入る。層別しない散布図では、性質の違う集団が混ざって関係が見えにくくなるという、この問題全体のテーマがここでも問われている。

要点

この問題から持ち帰ること

1層別がこの問題の背骨。 パレート図・ヒストグラム・散布図のどれも「全体では見えないが、ラインで分けると見える」構造になっている。手法が変わっても問われ方は同じ。
2片側規格の工程能力指数は (x̄ − SL)/(3s)。 両側規格の (SU−SL)/(6s) と混同しない。規格が片方しかない問題では必ずこちら。
3Cpk = 1 の意味は「平均から3s下げた点が規格線にちょうど届く」。 判定は 1.33以上で十分、1.00未満は不足。数値の意味を絵で持っておくと選択肢の妥当性を判断できる。
4特性要因図の特性は「現象」で書く。 「〜をなくす」「〜を高める」は目標であって特性ではない。対象は層別で絞り込んだ後のものを書く。
5相関が弱い＝その要因では説明できない。 「xを変えてもyが動かない」のではなく「xを固定してもyが散る＝x以外の原因がある」と読むのが正しい。次の一手は他要因の探索になる。
6図の選択肢は数値で絞る。 縦軸の目盛り・件数・平均・ばらつきといった、本文中に書かれた数字が判別材料。図の形を眺めて選ばない。
