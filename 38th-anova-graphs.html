一元配置実験 — グラフの見た目と、本当に有意かどうかは別物

因子Aを4水準・繰返し4回で実験した6パターンのグラフを見比べて「一番差が大きそうな図」「一番ばらつきが大きそうな図」を目で判断したあと、実際にそのばらつきが一番大きい図のデータで分散分析をすると――結果は有意ではない。グラフの印象と統計的な判定が食い違うことを、実際の計算で体感できる問題。

問題

一元配置実験の前提

データの構造式 x(ij) = μ + a(i) + ε(ij) 制約式: Σa(i) = 0 ε(ij) ~ N(0, σ(E)²)　（誤差は平均0・分散σ(E)²の正規分布に従う）

この前提のもとで、分散分析は「多数の母集団の (30) が一様に等しいかどうか」を検定する手法であり、完全ランダムな順序で実験することで誤差の (31) を保証できる、と問題文は続く。

(30) 母平均 (31) 独立性
(30)がなぜ「母平均」か: 一元配置実験で比べているのは「水準ごとの平均値a(i)に差があるか」。分散分析という名前に反して、調べているのは分散ではなく平均の違い――分散(ばらつき)は、平均の違いを判定するための「モノサシ」として使われているだけ。
(31)がなぜ「独立性」か: 実験の順序を固定してしまうと、時間帯や装置の温まり具合など「順序に伴う何か」が誤差に紛れ込み、誤差どうしが互いに関係を持ってしまう(独立でなくなる)。ランダムな順序にすることで、この隠れた関連を断ち切るのが目的。

STEP 2

図(a)のデータで分散分析を行う — (34)(35)

与えられている統計量は3つだけ。水準数a=4、繰返しni=4なので全データ数N=16。

与えられた統計量 Σx(ij) = 72.4　（合計） Σx(ij)² = 332.22　（2乗の合計） ΣT(i)² = 1318.8　（各水準の合計値T(i)を2乗して足したもの）
補正項と総平方和 CT = (Σx)² / N = 72.4² / 16 = 5241.76 / 16 CT = 327.61 S(T) = Σx² − CT = 332.22 − 327.61 S(T) = 4.61
要因Aの平方和 S(A) = ΣT(i)² / n(i) − CT = 1318.8 / 4 − 327.61 = 329.7 − 327.61 S(A) = 2.09

この「ΣT(i)²/n(i) − CT」という式は暗記するとすぐ抜けるが、何を測っているかから追うと崩れない。S(A)は本来「各水準の平均が全体平均からどれだけ離れているか」を、水準ごとのデータ数で重みづけして足したもの。

定義式から計算式へ（なぜΣT(i)²/n(i) − CTになるか） 定義: S(A) = Σ n(i)・(x̄(i) − x̄)²　　（水準平均と全体平均のズレの2乗を、データ数で重みづけて合計） 展開: Σn(i)x̄(i)² − 2x̄・Σn(i)x̄(i) + Σn(i)x̄² n(i)x̄(i) = T(i)、Σn(i)x̄(i) = Σx(ij) = N・x̄ を代入して整理すると S(A) = ΣT(i)²/n(i) − 2N・x̄² + N・x̄² = ΣT(i)²/n(i) − N・x̄² CT = (Σx)²/N = N・x̄² なので S(A) = ΣT(i)²/n(i) − CT
CTを引く理由: ΣT(i)²/n(i)だけだと「全体平均そのものの大きさ」による底上げ分(N・x̄²)が混ざっている。これはどの水準にも共通する定数なので、水準間の違いを見たいS(A)には不要——だからCT(=N・x̄²)を引いて取り除く。同じCTがS(T)の計算にも登場するのはこのため。
誤差の平方和（検算） S(E) = S(T) − S(A) = 4.61 − 2.09 = 2.52 → 表5.1にすでに与えられている S(E)=2.52 と一致。計算が合っている証拠

要点

この問題から持ち帰ること

1分散分析が調べているのは母平均が等しいかどうか。「分散」分析という名前だが、分散はそのための道具にすぎない。
2ランダムな実験順序は、誤差どうしの独立性を保証するために行う。
3グラフを読むときは「水準平均の振れ幅(効果)」と「各点の散らばり(誤差)」を別々に見る。同じグラフでも問われている観点が違えば答えも違う。
4平方和の基本形は毎回同じ: S(T)=Σx²−CT、S(A)=ΣT(i)²/n(i)−CT、S(E)=S(T)−S(A)。CT=(Σx)²/Nを最初に求める。
5グラフの見た目と統計的な有意性は一致するとは限らない。誤差が大きい実験では、多少の水準間の違いがあっても検定では「有意でない」となりうる。判断は必ず検定統計量とF表の比較で行う。
