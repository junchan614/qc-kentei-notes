QC検定2級 過去問解説 / 第40回 問6

S(B)とS(A×B)はほぼ同じ値なのに、判定が分かれる理由

要因B(平方和12.60)と交互作用A×B(平方和12.29)は、平方和だけを見ればほとんど同じ大きさ。ところが検定の結果はBは有意水準1%で有意、A×Bは5%でようやく有意と分かれる。答えは平方和の大きさではなく、その平方和が何個の自由度に分配されているかにある。

問題

与えられたデータ

製品の耐食性を向上させるため、因子A(4水準)×因子B(2水準)、繰返し数2回の繰返しのある二元配置実験を行った(全16個のデータ)。個々のデータは伏せられ、水準ごとの合計だけが与えられている。

表6.1 データ表（水準ごとの合計）
B1B2合計

さらに CT = T...²/N = 187.0²/16 = 2185.56、交互作用の平方和 S(A×B) = 12.29、誤差の平均平方 V(E) = 0.9325 が与えられている。水準数 a=4、b=2、繰返し r=2 なので、全データ数 N = a×b×r = 16。

STEP 1

自由度を数える — (31)(32)

二元配置(繰返しあり)の自由度は、水準数だけで機械的に決まる。データの中身を見る必要はない。φ(A×B)とφ(E)がなぜこの形になるかを「セル間/セル内」の2段階に分けて導出した補足は「φ(A×B)とφ(E)はどこから出てくるのか」を参照。

各要因の自由度 φ(A) = a − 1 = 4 − 1 = 3 φ(B) = b − 1 = 2 − 1 = 1 φ(A×B) = (a−1)(b−1) = 3 × 1 = 3 φ(E) = ab(r−1) = 4×2×(2−1) = 8 φ(T) = N − 1 = 16 − 1 = 15　（検算: 3+1+3+8 = 15 ✓）
(31) ウ. 3　（φ(A)） (32) ウ. 3　（φ(A×B)）
同じ答えが2回出てくるのは偶然ではない: 4水準のAは「4－1」で3、2水準のBと組み合わせた交互作用A×Bは「(4－1)×(2－1)」でやはり3。水準数の組み合わせ次第でφ(A)とφ(A×B)が同じ値になることは珍しくない。「工程能力指数」の回でCpUとCpkの答えが一致した(空欄番号が使い回された)のと同じ構造の罠で、計算を端折って前の答えを使い回すと逆に事故る。
STEP 2

要因Aの平均平方を求める — (33)

要因Aの平方和は、A水準ごとの合計T(i..)を2乗して足し、水準あたりの観測数(br=4)で割ってからCTを引く。

要因Aの平方和 S(A) S(A) = Σ(T(i..)²) / (br) − CT 　　= (8.5² + 33.7² + 61.1² + 83.7²) / (2×2) − 2185.56 　　= (72.25 + 1135.69 + 3733.21 + 7005.69) / 4 − 2185.56 　　= 11946.84 / 4 − 2185.56 = 2986.71 − 2185.56 S(A) = 801.15
要因Aの平均平方 V(A) V(A) = S(A) / φ(A) = 801.15 / 3 V(A) = 267.05
(33) カ. 267.05
選択肢ク「801.15」は罠: これはS(A)そのもので、V(A)ではない。φ(A)=3で割る一手間を忘れるとこの値を選んでしまう。選択肢オ「200.29」も罠で、801.15をφ(A)=3ではなくbr=4で割った値(801.15/4=200.29)。「水準あたりの観測数」と「自由度」を取り違えるとここに落ちる。
STEP 3

交互作用A×Bの平均平方を求める — (34)

S(A×B)=12.29はすでに与えられているので、STEP1で出したφ(A×B)=3で割るだけ。

交互作用の平均平方 V(A×B) V(A×B) = S(A×B) / φ(A×B) = 12.29 / 3 V(A×B) ≒ 4.10
(34) イ. 4.10
選択肢ア「1.54」も罠: 12.29をφ(A×B)=3ではなくφ(E)=8で割った値(12.29/8≒1.54)。「A×Bの行」を計算しているのに、下の「Eの行」の自由度を使ってしまう取り違えの罠。
STEP 4

有意性を判定する — (35)(36)

ここからは表に空欄はないが、(35)(36)に答えるにはF0を自分で計算する必要がある。要因Bの平方和も同じ要領で求め、V(E)=0.9325と比較する。

要因Bの平方和・平均平方 S(B) = (T.1.² + T.2.²) / (ar) − CT = (100.6² + 86.4²) / (4×2) − 2185.56 　　= (10120.36 + 7464.96) / 8 − 2185.56 = 2198.165 − 2185.56 S(B) ≒ 12.60　→　V(B) = S(B) / φ(B) = 12.60 / 1 = 12.60
3つの分散比F(0) F(0)_A = V(A) / V(E) = 267.05 / 0.9325 ≒ 286.38 F(0)_B = V(B) / V(E) = 12.60 / 0.9325 ≒ 13.51 F(0)_A×B = V(A×B) / V(E) = 4.10 / 0.9325 ≒ 4.40

(35) エ. AとB (36) ウ. A×B
平方和が同じでも判定が割れる理由: S(B)=12.60とS(A×B)=12.29はほぼ同じ大きさ。しかしBの自由度は1、A×Bの自由度は3。同じ量の「変動」でも、自由度1本に集中するBの方が平均平方(=1本あたりの取り分)は大きくなり、V(B)=12.60はV(A×B)=4.10の3倍以上になる。F検定は平方和そのものではなく平均平方の比で判定するので、見た目の平方和が近くても結論が逆転しうる。

要点

この問題から持ち帰ること

1繰返しのある二元配置の自由度は水準数だけで決まる: φ(A)=a−1、φ(B)=b−1、φ(A×B)=(a−1)(b−1)、φ(E)=ab(r−1)。データを見なくても先に埋められる。
2要因の平方和は「水準ごとの合計T²の和 ÷ その水準の観測数」− CT。Aなら br で割り、Bなら ar で割る。分母を自由度と取り違えない。
3平均平方は必ずS÷φ(自分の行の自由度)。他の行の自由度(特にφ(E))で割る取り違えが典型的な罠。
4有意性はF0=V/V(E)をF表の臨界値と比較して判定する。平方和の大小だけでは判定できない — 同じ平方和でも自由度が小さいほど平均平方は大きくなり、有意になりやすい。
5選択肢には「表の別のマスの値」「隣の行の自由度で割った値」が紛れ込む。今どの要因・どの列を計算しているかを都度確認する。
