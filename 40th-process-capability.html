QC検定2級 過去問解説 / 第40回 問2

CpUがCpLよりずっと小さい理由 — かたよりを考慮したCpk

工程は安定しているのに、なぜ規格外れが起きるのか。答えは「ばらつき」ではなく「平均のかたより」にある。Cp(ばらつきだけを見た指数)とCpk(かたよりまで考慮した指数)を並べて計算すると、CpUとCpLの非対称な差そのものが「どちらの規格に寄っているか」を教えてくれる。

問題

設定

K工場で生産する金属部品の外形寸法xの規格は95±5mm(下限規格LSL=90、上限規格USL=100)。最近、規格外れが発生している。ロットごとに5個抜き取り、群の数k=20でX̄-R管理図を作成したところ、管理限界線を越える点もクセもなかった。全データでヒストグラムを作ると正規分布とみなせ、x̄=97.33, V=s²=1.30。

STEP 1

工程の状態を確認する — (7)

管理図上で管理限界線を越える点がなく、点の並び方にもクセ(連・傾向など)がないというのは、工程が統計的管理状態にあることを意味する。

(7) イ. 安定状態
「安定 = 規格に収まる」ではない: 管理図が安定状態を示すのは「工程が偶然原因だけで動いている」ということであって、「規格を満たしている」こととは無関係。安定していても規格の中心からずれていれば規格外れは起こる。だからこそ次のステップで規格との対比(工程能力指数)に進む。
STEP 2

ばらつきだけを見る — Cp (8)

Cpは規格幅と工程のばらつき(6σ)だけを比べる指数で、平均がどこにあるか(かたより)は考慮しない。

計算 σ = √V = √1.30 = 1.1402 Cp = (USL − LSL) / 6σ = (100 − 90) / (6 × 1.1402) = 10 / 6.841 Cp = 1.46
(8) オ. 1.46
Cp=1.46は悪くない数字: 工程能力指数は一般に1.33以上あれば「十分」とされる目安がある。Cp単体を見る限りこの工程のばらつきそのものは問題ない。にもかかわらず規格外れが起きているなら、疑うべきは平均のかたよりだとここで見当がつく。
STEP 3

片側ずつ平均のかたよりを見る — CpU・CpL (9)(10)

上限規格側・下限規格側それぞれについて、平均から規格までの余裕を3σで測る。

上側工程能力指数 CpU = (USL − x̄) / 3σ = (100 − 97.33) / (3 × 1.1402) = 2.67 / 3.4205 CpU = 0.78
(9) ウ. 0.78
下側工程能力指数 CpL = (x̄ − LSL) / 3σ = (97.33 − 90) / (3 × 1.1402) = 7.33 / 3.4205 CpL = 2.14
(10) キ. 2.14
STEP 4

かたよりを考慮したCpk、そして対策 — (9)(11)(12)

Cpkは「規格に最も近い側」の余裕で決まる、つまりCpUとCpLの小さい方。

Cpkの定義 Cpk = min(CpU, CpL) = min(0.78, 2.14) = 0.78
(9) ウ. 0.78 (CpUと同じ値・同じ空欄番号)
空欄(9)が2回出てくる理由: 問題文は「上側工程能力指数CpUは(9)」と「平均のかたよりを考慮したCpkは(9)」の2か所で、同じ空欄番号(9)を使っている。これは誤植ではなく、Cpk=min(CpU,CpL)でCpUの方が小さいこの設問では、CpkとCpUの答えがそのまま一致することを見抜かせる作り。先にCpUとCpLを両方計算し、小さい方を選ばない限りこの一致には気づけない。

CpUがCpLに比べて小さいということは、平均が上限規格側に片寄っていることを意味する。対策は平均を規格の中心(95)に近づけること。

(11) ア. 小さい (12) エ. 下げる
補足

Cp・CpU・CpL・Cpkの関係を1枚で整理

4つの指数が「何を」「どちらの規格を基準に」測るか
指数式見ているもの値
Cp(USL−LSL)/6σ規格幅とばらつきだけ(平均は見ない)1.46
CpU(USL−x̄)/3σ上限規格までの余裕0.78
CpL(x̄−LSL)/3σ下限規格までの余裕2.14
Cpkmin(CpU, CpL)規格に一番近い側の余裕(実質的な工程能力)0.78
Cp > Cpkが意味すること: Cp=1.46は「ばらつきを規格幅と比べれば余裕がある」という理想値。実際のCpk=0.78との差(1.46−0.78=0.68)がそのまま「平均のかたよりによって失われた余裕」の大きさになる。Cp=Cpkなら平均は規格の中心に一致しており、差が大きいほどかたよりが深刻ということ。
要点

この問題から持ち帰ること

1Cpはばらつきだけ(6σと規格幅の比)、Cpk・CpU・CpLは平均の位置まで考慮する。Cp>Cpkなら平均が中心からずれている。
2CpU=(USL−x̄)/3σ、CpL=(x̄−LSL)/3σ。分母は6σでなく3σ(片側だけを見るため)。
3Cpk=min(CpU, CpL)。小さい方が実質的な工程能力であり、小さい側の規格に平均が寄っている。
4管理図の「安定状態」は工程が偶然原因だけで動いていることを示すだけで、規格を満たすことを保証しない。規格との対比には工程能力指数が必要。
5CpUとCpLの差が大きいほど平均のかたよりが大きい。対策は工程のばらつきを減らすことではなく、平均を規格の中心に寄せること。
