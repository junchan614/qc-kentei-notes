QC検定2級 概念の掘り下げ / 第40回 問1 関連

χ0²=S/σ0²は何を測っているのか — 分散の点推定になぜ標準偏差を使わないか

第40回 問1②では検定統計量として突然χ0²=S/σ0²という式が出てきて、点推定値も「mm²」という分散の単位で聞かれる。この2つは実は同じ1本の糸でつながっている。χ²分布の正体は「標準化した誤差の2乗和」であり、その糸をたどると、なぜ標準偏差ではなく分散を使うのかまで自然に見えてくる。

おさらい

問題の数値

ある工程の加工精度は、従来、母標準偏差が0.95(mm)であった。改善後のデータ: n=8, 平方和 S=1.526。改善後の加工精度(分散)が従来より向上した(=分散が小さくなった)かを有意水準5%で検定し、点推定値も求める。

σ0 = 0.95 → σ0² = 0.9025 n = 8 → 自由度 φ = n−1 = 7 S = 1.526 (平方和 = Σ(xi−x̄)²)
STEP 1

χ²分布の定義 — 「標準化した誤差の2乗和」

χ²分布は、標準正規分布N(0,1)に従う確率変数を何個か2乗して足したものが従う分布として定義される。まずは母平均μが既知の理想的な場合から考える。「なぜ2乗するのか」自体を掘り下げたい場合はなぜ「カイ二乗」は二乗なのかを参照。

母平均μ・母分散σ²が両方既知のとき Z(i) = (x(i) − μ) / σ 　← 各データを標準化(平均0・分散1の物差しで測り直す) Z(1)² + Z(2)² + ... + Z(n)² = Σ((x(i)−μ)/σ)² この和は χ²(n) 分布に従う (自由度n = 足した独立な項の数)

ところが実際にはμは未知で、代わりに標本平均x̄を使うしかない。ここで1つ制約が生まれる: 「x(i)−x̄」をすべて足すと必ず0になる(平均からの偏差の合計は常に0)という関係が、n個の偏差の中に1本の縛りを作る。この縛りの分だけ、自由に動ける項の数(自由度)が1つ減る。

μが未知で、代わりにx̄を使うとき S = Σ(x(i) − x̄)² 　(平方和。母平均μではなく標本平均x̄からの偏差) S / σ² = Σ((x(i)−x̄)/σ)² この和は χ²(n−1) 分布に従う (自由度がn−1に1つ減る)
自由度がn−1になる理由の詳細: なぜ「1つの縛り」が「自由度が1減る」ことに対応するのかは、自由度の正体で「独立な2本立て」「1本を切り分ける」の2パターンに整理して解説している。ここでのS=Σ(x(i)−x̄)²は「1本を切り分ける」型で、全体n個の情報からx̄の計算に1個分の情報が使われ、残りn−1個分だけが「ばらつき」として残る。
STEP 2

検定統計量χ0²の意味

STEP1の式で、σ²のところに帰無仮説H(0)の値σ0²を代入すると、そのまま検定統計量になる。

検定統計量 χ0² = S / σ0² = 1.526 / 0.9025 = 1.691 H(0): σ² = σ0² が正しければ、χ0²はχ²(7)分布に従うはず

つまりχ0²は、「実際に観測されたばらつきSが、従来の分散σ0²の何倍あるか」を測る物差し。H(0)が正しければ、この比はχ²(7)分布が示す「普通の範囲」に収まるはずで、極端に小さければ「分散が縮んだ(向上した)」、極端に大きければ「分散が広がった(悪化した)」と判断できる。

STEP 3

(6) なぜ標準偏差でなく分散を点推定するのか

STEP1の関係 S/σ² ~ χ²(n−1) から、σ²の不偏推定量が直接手に入る。χ²(n−1)分布の平均はn−1なので、E[S/σ²]=n−1、つまりE[S/(n−1)]=σ²が成り立つ。

分散の不偏推定量(点推定値) V = S / (n−1) = 1.526 / 7 = 0.218 (mm²) E[V] = σ² 　← 過大でも過小でもない、ちょうどよい推定量
(6) イ. 0.218 (mm²)

ここで「じゃあ標準偏差は√Vでいいのでは」と思うかもしれないが、それは不偏推定量にならない。平方根は凹関数なので、平均を取ってから根を取るのと、根を取ってから平均を取るのとでは結果が変わり、必ず過小評価側にずれる(イェンセンの不等式)。

分散の推定と標準偏差の推定、どちらが素直か
分散 V=S/(n−1)標準偏差 s=√V
χ²分布との対応S/σ² ~ χ²(n−1) から直接出てくるχ²分布は分散側の分布。標準偏差側には対応する簡単な分布がない
不偏性E[V] = σ² (不偏)E[s] ≠ σ (過小評価にバイアス)
補正の要否不要不偏にするには自由度依存の補正係数(c4など)が必要
単位mm² (分散の単位)mm (標準偏差の単位)
問題文の「(mm²)」が最大のヒント: 設問はわざわざ単位を(mm²)と明記している。これは「分散の点推定値を答えよ」という指示そのもの。ここでうっかり√0.218=0.467(mm)と標準偏差に変換して答えると、単位が合わず単純ミスになる。さらに言えば、その0.467という値自体も不偏推定量ではないので、たとえ単位をmmに読み替えても正しい推定値としては扱えない。
管理図の係数A₂・d₂と同じ事情: 管理図の係数の正体で扱ったd₂(範囲Rからσを推定する補正係数)も、まさに「標準偏差を不偏推定するには補正が要る」問題への対処法の1つ。QC検定2級の範囲では、この種の補正は管理図の係数表という形で与えられるだけで、s(標本標準偏差)側から直接補正する係数(c4)までは扱わない。だからこそ検定・推定の問題では、素直に不偏推定量が手に入る分散のまま答えさせる設計になっている。
要点

この資料から持ち帰ること

1χ²分布の正体は「標準化した誤差(標準正規分布)の2乗和」。母平均が未知でx̄を使うと、自由度が1つ減ってχ²(n−1)になる。
2S/σ0² は「観測されたばらつきが従来の分散の何倍か」を測る物差し。H(0)のもとではχ²(n−1)分布に従うはずの値。
3S/σ² ~ χ²(n−1) という関係から、σ²の不偏推定量V=S/(n−1)が直接手に入る。これがχ²検定と点推定が同じ問題に同居している理由。
4標準偏差s=√Vは不偏推定量ではない(平方根を取ると過小評価にバイアスがかかる)。だから点推定は分散のまま答えるのが正しく、単位(mm²)がそのサインになっている。
