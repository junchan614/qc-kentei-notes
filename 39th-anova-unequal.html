実験が予定通り終わらなかったときの一元配置分散分析

接着剤4種類(A1〜A4)を各4回、計16回実験する計画だったが、都合で15回で打ち切りになり、A2だけ3回しかデータがない。繰り返し数が水準ごとに違う一元配置は第36回 問5と同じ型だが、今回は最良水準がいちばんデータの少ない水準という、実務でよくある悩ましい状況が付いてくる。

問題

与えられたデータ

接着剤の種類(現状A1・候補A2〜A4)を因子として、接着強度の実験を行った。計画では各水準4回・計16回のはずが、15回で打ち切られたため、A2だけ繰り返し数が3になっている。

①

グラフで効果を見る — (17)

データをグラフ化すると、接着強度に対する接着剤種類の効果はありそうに見える、と問題文にある。実際にどんな形をしているかは、水準ごとの平均を計算すれば先取りできる。

正しい図の選び方: 巻末の4つのグラフ(ア〜エ)から選ぶ設問だが、選ぶ基準はこの4つの平均値をそのままプロットした形と一致するかだけ。A2が頭ひとつ抜けて高く(24.7)、A4がいちばん低い(20.5)という山型(A1→A2でピーク→A3→A4で下降)になっているかを確認する。選択肢の中には縦軸の目盛りがまったく違う(実際の数値20〜25の範囲に収まらない)グラフが紛れていることが多く、目盛りを見ずに形だけで選ぶと引っかかる。
②

分散分析表の作成 — (18)(19)(20)

繰り返し数が水準ごとに違うので、要因Aの平方和は各水準ごとにT²をその水準のnで割ってから合計する。

修正項と全平方和 CT = (Σx)² / N = 329² / 15 = 108241/15 = 7216.07 S(T) = ΣΣx² − CT = 7277 − 7216.07 = 60.93
要因Aの平方和 — 各水準はT²/n(i)で割ってから足す ΣT(i)²/n(i) = 7056/4 + 5476/3 + 7921/4 + 6724/4 　　　　　 = 1764.00 + 1825.33 + 1980.25 + 1681.00 = 7250.58 S(A) = 7250.58 − 7216.07 = 34.52
(18) イ. S(A) = 34.52
自由度 φ(A) = a−1 = 4−1 = 3(表にすでに記載) φ(T) = N−1 = 15−1 = 14 φ(E) = φ(T) − φ(A) = 14 − 3 = 11
(19) ウ. φ(E) = 11
φ(E)のもう1つの求め方: Σ(n(i)−1) = (4−1)+(3−1)+(4−1)+(4−1) = 3+2+3+3 = 11。データが足りない水準は自由度もその分だけ減る——「打ち切りで1個データを失う」ことと「誤差の自由度が1減る」ことは同じ現象の裏表になっている。
分散比 V(A) = S(A)/φ(A) = 34.52/3 = 11.51 V(E) = S(E)/φ(E) = 26.42/11 = 2.40 F(0) = V(A)/V(E) = 11.51/2.40 = 4.79
(20) イ. F(0) = 4.79
③

有意性の判定 — (21)

φ(A)=3、φ(E)=11でのF表の値と比較する。

F表の値との比較 F(3,11;0.05) = 3.59, F(3,11;0.01) = 6.22 F(0) = 4.79 → 3.59 < 4.79 < 6.22
(21) ウ. 5%では有意だが、1%では有意でない
④

最適水準の推定 — (22)(23)(24)

接着強度がもっとも大きいのはA2(平均24.7)。ここが最適水準になる。

最適水準の点推定・区間推定 点推定値: x̄(A2) = 74/3 = 24.7 区間推定: x̄(A2) ± t(11,0.025)·√(V(E)/n(A2)) 　　　　 = 24.7 ± 2.201×√(2.40/3) = 24.7 ± 1.97 = (22.7, 26.7)
(22) ウ. 24.7 (23) ウ. 22.7, 26.7

現状水準A1と最適水準A2との母平均の差も推定する。点推定値は問題文に-3.7と与えられている。

差の区間推定 — 2つの水準の差はn(i)が異なる分だけ式が変わる 点推定: x̄(A1) − x̄(A2) = 21.0 − 24.7 = −3.7 区間推定: (x̄(A1)−x̄(A2)) ± t(11,0.025)·√{V(E)(1/n(A1) + 1/n(A2))} 　　　　 = −3.7 ± 2.201×√{2.40×(1/4 + 1/3)} = −3.7 ± 2.61 = (−6.3, −1.1)
(24) ア. −6.3, −1.1
1/n(i)+1/n(j)の作り方は第37回問5と同じ: 「1つの水準の推定」はV(E)/n(i)、「2つの水準の差の推定」はV(E)(1/n(i)+1/n(j))。今回はn(A1)=4とn(A2)=3で値が違うので、単純に「幅を√2倍する」だけでは済まない——n(i)が揃っている問題との違いがここに出る。
補足

「打ち切り」が推定の不確かさに直接効いてくる

今回、最良水準に選ばれたA2は、皮肉にも打ち切りでデータが1個減った水準。n=3という少ないデータで出た平均24.7が、本当に他の水準より優れているのか、区間推定の幅を見て確認する必要がある。

もしA2がn=4のままだったら(参考)
n区間推定の幅の目安 ∝ 1/√n
実際(n=3で打ち切り)31/√3 = 0.577
計画通り(n=4)41/√4 = 0.500
実務的な教訓: 打ち切りで1個データを失ったA2は、区間推定の幅が計画時より広がっている(√(1/3)は√(1/4)よりおよそ15%大きい)。「平均値がいちばん高い」ことと「その値が信頼できる」ことは別問題——データ数が少ない水準の推定は、区間推定の幅を見て初めて信頼度が判断できる。これは分散分析表の数値だけを見ていては気づけない、表の裏側にある情報。
要点

この問題から持ち帰ること

1繰り返し数が不揃いなときの要因平方和は S(A) = Σ(T(i)²/n(i)) − CT。各水準は自分のn(i)で割ってから合計する。
2誤差の自由度は φ(E) = N−a = Σ(n(i)−1)。打ち切りでデータが1個減れば、誤差の自由度も1減る。
3F0が5%点と1%点の間に入る判定(「5%では有意だが1%では有意でない」)は頻出パターン。2つの境界値を両方書き出してから比較する。
4最適水準の区間推定はV(E)/n(i)、2水準の差の区間推定はV(E)(1/n(i)+1/n(j))。n(i)が水準ごとに違う問題では、この式の違いが特に効いてくる。
5データ数が少ない水準が最良になったときは、点推定値だけでなく区間推定の幅を見て、その優位性がどれだけ確からしいかを判断する。
