概念の掘り下げ / 第40回 問5 関連

なぜnp̄(1−p̄)なのか — np管理図の3σの正体

「不適合品数のnp管理図」で使った UCL/LCL = np̄ ± 3√(np̄(1−p̄)) という式。この√の中身は暗記するものではなく、製品1個ずつを「合格/不合格のコイン投げ」とみなし、それをn個分足し合わせるという、ごく単純な発想から機械的に出てくる。

STEP 1

製品1個を確率変数として見る

検査する製品1個を、不適合なら1・適合なら0を取る確率変数 Xi とする。不適合になる確率をpとすると、Xiの分布(ベルヌーイ分布)は次の2通りしかない。

1個あたりの平均（期待値） E[Xi] = 0×(1−p) + 1×p = p
1個あたりの分散 — ここが核心 Xi は0か1しか取らないので、Xi² = Xi が常に成り立つ（0²=0、1²=1） よって E[Xi²] = E[Xi] = p V[Xi] = E[Xi²] − (E[Xi])² = p − p² V[Xi] = p(1−p)
「2乗しても値が変わらない」という特殊性: 0/1しか取らない変数だけが持つ性質。この一手間(Xi²=Xiに気づく)だけで、分散の公式 V=E[X²]−(E[X])² から自動的に p(1−p) という積の形が出てくる。丸暗記する式ではなく、ここまでたどれば導出できる。
STEP 2

p(1−p)という形を見る

p(1−p)をpの関数としてグラフに描くと、p=0.5を頂点とする上に凸の放物線になる。

直感との一致: 不適合品率が0%や100%の工程は「毎回結果が同じ」なのでばらつきがない(分散0)。半々の確率が一番読めない、というのは感覚的にも自然で、グラフの形がその直感をそのまま表している。
STEP 3

n個ぶん足し合わせる — 分散の加法性

群のn個の製品は互いに独立に検査される。n個の合計X=X1+X2+⋯+Xnが「群の不適合品数」で、これがnp管理図で打点する値そのもの。独立な確率変数の和では、分散はそのまま足し算になる（「なぜ√nで割るのか」で見たのと同じ原理）。

合計Xの分散と標準偏差 V[X] = V[X1] + V[X2] + ⋯ + V[Xn] = n・p(1−p) σ = √(V[X]) = √(np(1−p))
標準偏差は個数分の1にはならない: 「なぜ√nで割るのか」で見た標本平均の場合はn個の平均を扱うのでσ/√nと小さくなった。np管理図で扱うのはn個の合計(個数)なので逆にnが掛かり、√(np(1−p))と大きくなる。同じ「分散の加法性」から出発しても、最後に割るか(平均)・割らないか(合計)で結果の向きが逆になる。
STEP 4

実際の数値で確認する

「第40回 問5」のデータ(n=200, p̄=0.05)にそのまま当てはめる。

標準偏差から管理限界線まで V[X] = n・p̄(1−p̄) = 200 × 0.05 × 0.95 = 9.5 σ = √9.5 ≒ 3.082 3σ ≒ 9.25 CL = np̄ = 10.0　→　UCL = 10 + 9.25 ≒ 19.2　LCL = 10 − 9.25 ≒ 0.8

段階式意味
1個V[Xi] = p(1−p)Xi²=Xiという0/1特有の性質から
n個の合計V[X] = n・p(1−p)独立な和は分散が足し算（分散の加法性）
標準偏差σ = √(np(1−p))分散の単位を「個数」に戻すための√
要点

持ち帰ること

1製品1個は0/1しか取らない確率変数。Xi²=Xiという特殊性から、分散が自動的に V[Xi]=p(1−p) という積の形になる。
2p(1−p)はp=0.5で最大・p=0や1で0になる上に凸の放物線。不適合品率が五分五分に近いほど、1個あたりのばらつきは大きい。
3n個の独立な和では分散がそのまま足し算になる(分散の加法性)。個数を数えるnp管理図では、この和にnが掛かるぶん標準偏差は√n倍に大きくなる(標本平均のσ/√nとは逆向き)。
4√(np̄(1−p̄))は暗記する公式ではなく、「1個の分散 p(1−p)」×「n個ぶん(分散の加法性)」の√を取っただけという2段階の掛け算。
