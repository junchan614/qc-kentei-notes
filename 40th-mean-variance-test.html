QC検定2級 過去問解説 / 第40回 問1

重量は増えたか、精度は上がったか — t検定とχ²検定の使い分け

1つの大問の中に「①母平均の検定」と「②母分散の検定」が並んで出てくる構成そのものが出題ポイント。同じ有意水準5%・同じ片側検定でも、①はt分布、②はχ²分布を使う。さらに①は「増えたか」(上側検定)、②は「向上した(ばらつきが減った)か」(下側検定)と棄却域の向きが逆になる点も見落としやすい。

問題

設定

①重量: 従来の製造方法での重量の母平均は9.1(g)。原材料の成分比を変更し、重量を増やすことを狙った。変更後のデータ: n=8, 平均値 x̄=9.3, 不偏分散 V=0.72。母平均が従来より大きくなったといえるか、有意水準5%で検討する。

②加工精度: 従来の母標準偏差は0.95(mm)。工程を改善し、加工精度(ばらつき)の向上を狙った。改善後のデータ: n=8, 平方和 S=1.526。母分散が従来より向上した(小さくなった)といえるか、有意水準5%で検討する。

STEP 1

① 母平均の検定(片側t検定) — (1)(2)(3)

母標準偏差が未知で、標本から不偏分散Vを計算しているのでt検定を使う。「大きくなったか」だけを問う片側(上側)検定になる。

仮説と検定統計量 H(0): μ = 9.1　H(1): μ > 9.1(上側検定)　自由度 φ = n−1 = 7 t0 = (x̄ − μ0) / √(V/n) = (9.3 − 9.1) / √(0.72/8) = 0.2 / √0.09 = 0.2 / 0.3 t0 = 0.667
(1) ウ. 0.667
棄却域の境界値 上側片側検定・φ=7・α=0.05 → t表から t(7, 0.05) = 1.895 判定: t0 = 0.667 < 1.895 → 棄却域に入らない → 有意でない(大きくなったとはいえない)
(2) キ. 1.895
信頼率95%の信頼区間の幅 区間推定は両側なので t(7, 0.025) = 2.365 を使う(検定の棄却域と表引きする列が違う点に注意) ± t(7,0.025) × √(V/n) = ± 2.365 × 0.3 = ± 0.7095 ± 0.710 (g)
(3) エ. 0.710
棄却域と信頼区間でt表の列が違う: 検定は片側(α=0.05の列)、信頼区間の幅は両側(α/2=0.025の列)を見る。同じt(7)でも1.895と2.365を取り違えると(2)と(3)を逆に答えてしまう。
STEP 2

② 母分散の検定(片側χ²検定) — (4)(5)(6)

「ばらつきが向上した(減った)か」を問う検定なので、母標準偏差ではなく母分散についての検定になる。検定統計量は平方和Sと従来の母分散σ0²の比。「向上した」= 分散が小さくなったことを示したいので、棄却域はχ²分布の下側に置く。

仮説と検定統計量 H(0): σ² = 0.95² = 0.9025　H(1): σ² < 0.9025(下側検定)　自由度 φ = n−1 = 7 χ0² = S / σ0² = 1.526 / 0.9025 χ0² = 1.691
(4) エ. 1.691
棄却域の境界値 下側検定なので、上側95%点(=下側5%点)を使う → χ²表から χ²(7, 0.95) = 2.17 判定: χ0² = 1.691 < 2.17 → 棄却域に入る → 有意(向上したといえる)
(5) オ. 2.17
工程改善後の加工精度(分散)の点推定値 V = S / φ = 1.526 / 7 V = 0.218 (mm²)
(6) イ. 0.218
補足

①と②、何が同じで何が違うか

①母平均の検定 と ②母分散の検定 の対応
① 母平均② 母分散
調べたいこと重量が増えたかばらつきが減った(向上した)か
使う分布t分布 (φ=7)χ²分布 (φ=7)
検定統計量t0=(x̄−μ0)/√(V/n)χ0²=S/σ0²
棄却域の向き上側 (大きい方)下側 (小さい方)
境界値t(7,0.05)=1.895χ²(7,0.95)=2.17
向きが逆になる理由: ①は「大きくなった」ことを示したいので統計量が大きいほど有意 → 上側検定。②は「ばらつきが減った」ことを示したいので統計量(S/σ0²、従来との比)が小さいほど有意 → 下側検定。「片側検定=常に上側」と思い込むと②で符号を間違える。
①は非有意、②は有意という結果の非対称性: 標本平均は9.1→9.3に増えているのに、①の検定は有意でない(サンプルが8個では差を検出しきれない)。一方、②はサンプル数が同じ8個でも有意になる。「見た目の変化」と「統計的に意味のある変化」は別物であることが、この一問の中で対比されている。
要点

この問題から持ち帰ること

1母平均の検定(σ未知)はt検定、統計量はt0=(x̄−μ0)/√(V/n)、自由度はn−1。
2母分散の検定はχ²検定、統計量はχ0²=S/σ0²(平方和Sをそのまま使う。Vやnで割らない)。
3「増えた/大きくなった」は上側検定、「ばらつきが減った/向上した」は下側検定。片側検定だからと機械的に上側だけを見ない。
4検定の棄却域(片側α)と信頼区間の幅(両側α/2)は、同じt表の別の列を使う。φが同じでも数値は違う。
5点推定値は検定と別物。分散の点推定は不偏分散 V=S/(n−1) であり、検定統計量χ0²=S/σ0²とは分母が違う。
