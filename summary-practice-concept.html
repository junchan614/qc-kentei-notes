品質の概念・QC的ものの見方・倫理と社会的責任

この3分野は独立した知識ではなく、扱うスコープ(範囲)の広さが違うだけの一つながりの考え方。「品質の概念」は製品・サービス単位の話(ねらいの品質・できばえの品質・狩野モデルなど)、「QC的ものの見方・考え方」はそれを組織全体でどう実践するかという行動原則(重点指向・全員参加・事実に基づく管理など)、「倫理・社会的責任」はさらに組織の外(社会・法律)まで広げた話。他の分野を勉強していて出てくる前提知識でもある。過去問そのものは掲載していません。お手元の過去問題集と合わせて読む前提です。

地図

3分野はスコープの広さの違い

3つの分野は「誰にとっての品質か」という視点の広がりで並べると理解しやすい。中心にあるのは1つの製品・サービスの品質(ねらいの品質・できばえの品質・狩野モデル)。それを実現するための組織としての行動原則がQC的ものの見方・考え方(重点指向、全員参加、事実に基づく管理、後工程はお客様、など)。さらにその外側、組織の外の社会に対する責任が倫理・社会的責任(コンプライアンス、CSR、PL法、環境配慮)にあたる。

もう一つの軸として、マーケットイン(顧客の声を起点に商品を作る)とプロダクトアウト(自社の技術・シーズを起点に作る)という「どちらの方向で企画するか」の対立軸がある。QC的ものの見方・考え方では、後工程はお客様・源流管理・事実に基づく管理などの各原則が、最終的にはすべて「顧客に満足してもらう」という一点に収束するように作られている。

出題範囲表の小項目のうち、過去6回の担当分野の空欄には出てこなかったもの。次の回に出てもおかしくない範囲として押さえておく。

品質の概念
  • 要求品質と品質要素: 顧客が製品・サービスに求める性質(要求品質)を、設計・製造で扱える具体的な特性(品質要素)に置き換えていく考え方。品質機能展開(QFD)ともつながる。
  • 品質特性と代用特性: 顧客が実際に求めている性質(品質特性)を、測定しやすい別の特性(代用特性)に置き換えて管理すること。「対比」の項の当たり前品質などとは別の切り口。
QC的ものの見方・考え方
  • 後工程はお客様: 次の工程やその先の顧客を「お客様」とみなし、不良を送らないという考え方。全員参加・重点指向と並ぶ基本原則の一つ。
  • プロセス重視: 結果だけでなく、結果を生み出す工程(プロセス)そのものを管理・改善の対象にする考え方。「品質は工程で作り込む」という広い意味で使われる。
  • 特性と要因・因果関係: 結果(特性)とその原因(要因)の関係を明らかにしてから対策を打つという、QC的な問題解決の基本姿勢。
  • 応急対策・再発防止・未然防止・予測予防: 不適合が起きた後の対応(応急対策→再発防止)と、起きる前の備え(未然防止→予測予防)の段階の違い。
  • 源流管理: 問題が発生してから対処するのではなく、企画・設計など上流の段階で品質を作り込む考え方。
  • 目的志向: 手段そのものが目的化しないよう、常に「何のためにやるのか」を意識する考え方。
  • QCD+PSME: 品質(Q)・コスト(C)・納期(D)に加え、生産性(P)・安全(S)・モラール(M)などを含めて経営の対象を広くとらえる考え方。
  • 見える化・潜在トラブルの顕在化: 管理のための状況をグラフや図解で誰にでも分かる形にし、隠れた問題を早期に見つけられるようにすること。
  • ばらつきに注目する考え方: 平均値だけでなく、データのばらつき(分布)そのものに着目して工程を見る考え方。統計的方法の基礎ともつながる。
倫理・社会的責任
  • 品質管理に携わる人の倫理: データの改ざん・検査の不正など、品質にかかわる個人の職業倫理。コンプライアンスの土台にある個人の姿勢。
  • 社会的責任の広がり: 過去問ではPL法・3R・CSR・コンプライアンス窓口が出題されたが、人権への配慮や地域社会への貢献など、社会的責任のより広い範囲は今のところ確認できていない。
確認

新鮮な確認問題

過去問の文をそのまま使わず、形式を変えて出題する。開いて答え合わせをすること。

コンプライアンス相談窓口で「相談内容を第三者に漏らさない」という性質を何と呼ぶか。ア: 透明性 / イ: 秘匿性 / ウ: CSR / エ: リスクマネジメント
イ: 秘匿性。個人情報を含むデリケートな内容を安心して相談してもらうには、内容が漏れない秘匿性が鍵になる。「広く公開して信頼を得る」透明性とは向きが逆の性質なので対で覚える。
狩野モデルで「あってもなくても顧客満足度にほとんど影響を与えない」品質要素を何と呼ぶか。ア: 当たり前品質 / イ: 一元的品質 / ウ: 無関心品質 / エ: 魅力的品質
ウ: 無関心品質。当たり前品質は「不充足のときだけ不満が出る」、一元的品質は「充足・不充足の両方に反応が出る」、無関心品質は「どちらでも反応が変わらない」要素。
正誤: 「ねらいの品質は設計段階で目標として定めるものなので、実際の工程に作り込む実力があるかどうかは、その時点で考える必要はない」。この記述は正しいか誤りか。誤りならどこが誤りか。
誤り。ねらいの品質(設計品質)は顧客の要望から展開して決められるものであり、工程にそれを作り込む実力の有無を確認しないまま量産に移行してはいけない。設計と製造が切り離された話ではなく、両方が揃って初めて顧客満足につながる。
ある企業が、新商品の企画で自社の技術シーズを起点に「これを応用すれば何ができるか」を検討した。この進め方に最も近い考え方はどれか。ア: マーケットイン / イ: プロダクトアウト / ウ: 後工程はお客様 / エ: 源流管理
イ: プロダクトアウト。顧客の声やアンケートを起点にするマーケットインとは逆に、自社の技術・強みを起点に企画する進め方。どちらか一方が正解というわけではなく、両方の視点をバランスさせる企業が多い。
工程で不適合が見つかったとき、まず不適合品を取り除き(応急対策)、その後で「同じ原因で二度と不適合が起きないよう」工程を改善した。この2番目の活動を何と呼ぶか。ア: 応急対策 / イ: 再発防止 / ウ: 未然防止 / エ: 予測予防
イ: 再発防止。「すでに起きた問題」の原因を取り除くのが再発防止、「まだ起きていない問題」を想定して手を打つのが未然防止・予測予防。段階の順番(応急対策→再発防止→未然防止)で覚える。
第36回では「顧客が製品・サービスを継続的に購入したいと望む意思」を指す言葉が、第40回では「常にお客様の視点に立って行動する」考え方が問われた。それぞれに当てはまる用語を選べ。ア: 顧客満足 / イ: 顧客ロイヤリティ / ウ: 顧客志向(顧客重視) / エ: 顧客価値
第36回はイ: 顧客ロイヤリティ、第40回はウ: 顧客志向(顧客重視)。顧客満足(CS)の蓄積が長期的に顧客ロイヤリティに影響するという流れと、そもそも顧客を判断の中心に置くという考え方そのものである顧客志向は別物として区別する。
複数ある問題点の中から、効果の大きいものに絞って資源を集中投入する考え方を何と呼ぶか。ア: 重点指向 / イ: 全員参加 / ウ: 継続的改善 / エ: 人間性尊重
ア: 重点指向。パレート図を使って「どこに絞るか」を決めるときの基本的な考え方。似た言葉の全員参加は「誰が取り組むか」、継続的改善は「いつまで続けるか」という別の軸の話。
正誤: 「CSR(企業の社会的責任)は、法令を守ってさえいれば十分に果たされる」。この記述は正しいか誤りか。誤りならどこが誤りか。
誤り。法令遵守(コンプライアンス)はCSRの土台の一部にすぎない。CSRはそれに加えて、環境保全や地域社会への貢献など、法律で義務付けられていない範囲まで含めて企業が果たすべき責任を指す。
ある企業が「不適合の再発を防ぐだけでなく、まだ一度も起きていないトラブルもあらかじめ想定して手を打つ」活動に力を入れている。これは何と呼ばれる考え方か。ア: 再発防止 / イ: 未然防止 / ウ: 応急対策 / エ: 源流管理
イ: 未然防止。再発防止は「一度起きたことを繰り返さない」対応であるのに対し、未然防止は「まだ起きていないことを想定する」点が異なる。さらに先回りして予測するのが予測予防。
実際に測定・評価するのが難しい品質特性の代わりに、測定しやすい別の特性を使って評価すること、またはその特性を何と呼ぶか。ア: 品質特性 / イ: 代用特性 / ウ: 要求品質 / エ: 社会的品質
イ: 代用特性。例えば「使いやすさ」という品質特性を直接数値化しにくいとき、操作にかかる時間などの測定しやすい代用特性に置き換えて管理する。
第37回では「性能などが満たされれば満足、満たされなければ不満をもたらす」品質要素が問われた。狩野モデルでこれに当てはまるものを選べ。ア: 当たり前品質 / イ: 一元的品質 / ウ: 無関心品質 / エ: 魅力的品質
イ: 一元的品質。当たり前品質は「満たされて当然、満たされなければ不満」という片方向の反応であるのに対し、一元的品質は充足度に比例して満足・不満の両方が動く点が違う。
ある製造業者の製品の欠陥が原因で消費者がけがをした場合、被害者が製造業者の過失を証明できなくても賠償責任を問える根拠となる法律はどれか。ア: 労働安全衛生法 / イ: 製造物責任法(PL法) / ウ: 品質マネジメントシステム / エ: 消費者基本法
イ: 製造物責任法(PL法)。1995年施行。製造物責任は無過失責任であり、被害者ではなく製造業者ら(製造物を引き渡した側)に立証の負担が求められる点が特徴。
