同じデータを3通りに計算する — 直接計算・変数変換・度数分布表

25個のサンプルの平均値と標準偏差を、①生データから直接・②変数変換してから・③度数分布表を作ってからの3つの方法で求める問題。結論だけ言えば、②は元の値と完全に一致するが、③は一致しない(が実用上は無視できる差)。この「一致する/しない」の境目がどこにあるかが、この問題の一番のポイント。

問題

与えられたデータ

製品Qから25個のサンプルをランダムに取り、特性値xを測定した(表1.1、単位省略)。データの合計は4676.0、2乗和は874610.68とすでに計算されている。

①

生データから直接計算 — (1)(2)

平均値 x̄ と標準偏差 s は、いつも通り偏差平方和 S を Σx と Σx² から求めるところから始める。

計算 x̄ = Σx / n = 4676.0 / 25 = 187.04 S = Σx² − (Σx)²/n = 874610.68 − 4676.0²/25 = 874610.68 − 874599.04 = 11.64 s² = S / (n−1) = 11.64 / 24 = 0.485 s = √0.485 = 0.696
(1) x̄ = 187.04 (2) s = 0.696
②

変数変換してから計算 — (3)(4)

先輩のアドバイス通り、u = (x−a)×b(a=185.0, b=10)に変換して桁数を減らす。最初の測定値186.1を変換すると…

最初のデータの変換 u = (186.1 − 185.0) × 10 = 1.1 × 10 = 11
(3) u = 11

変換後のデータは合計510、2乗和11568になった。これらから ū と s(u) を求め、a とbを使って元のスケールに戻す。

変換後データでの計算 → 元に戻す ū = 510 / 25 = 20.4 x̄ = a + ū/b = 185.0 + 20.4/10 = 187.04 ← ①と完全一致 S(u) = 11568 − 510²/25 = 11568 − 10404 = 1164 s(u)² = 1164/24 = 48.5, s(u) = √48.5 = 6.964 s = s(u)/b = 6.964/10 = 0.696 ← ①と完全一致
(4) ア. 変数変換をしても、元に戻せば、平均値・標準偏差とも完全に一致する
なぜ完全に一致するのか: u=(x−a)×b は1個の測定値を1個の変換値へ移すだけの操作で、情報は何も失われていない(a、bを使えばいつでも元のxに戻せる)。だから平均や分散のような統計量も、変換前後で計算式の上で完全に対応し、丸めや近似の誤差が入り込む余地がない。実際、上の計算で s²=0.485(①)と s(u)²/b²=48.5/100=0.485(②)は小数点以下まで同じ値になっている。

補足

なぜ②は完全一致し、③は一致しないのか

②の変数変換 u=(x−a)×b は、1個のデータを1個の値に移すだけで、逆算すればどのデータも寸分違わず復元できる。一方③の度数分布表は、区間内のすべてのデータを、区間の中心値1つで代表させてしまう。この「代表させる」ときに、実際の値と中心値との差が誤差として発生する。

覚え方: 「変換」は服を着替えるだけで中身(情報量)は同じ。「度数分布表」は複数人をひとまとめにして代表値1つで扱うので、個人差の情報が失われる。ズレの大きさは区間の幅(今回は0.5)が広いほど大きくなる。
要点

この問題から持ち帰ること

1偏差平方和は S = Σx² − (Σx)²/n、標準偏差は s = √(S/(n−1))。これはどの方法でも共通の型。
2線形変換 u=(x−a)×b は情報を失わない可逆操作。元に戻せば平均・標準偏差とも完全に一致する(x̄=a+ū/b、s=s(u)/b)。
3度数分布表は区間内のデータを中心値1つで代表させる近似。平均・標準偏差とも直接計算とは必ずしも一致しないが、実用上は無視できる程度の差にとどまる。
4「完全に一致する」か「一致しないが問題ない程度」かは、その変換が情報を保持するか(1対1)、潰すか(多対1)で見分けられる。
