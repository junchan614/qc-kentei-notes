分散分析表から回帰直線、そして点推定まで一直線に解く

Sxx・Syy・Sxyが最初から与えられている単回帰の問題。分散分析表で「関係があるか」を検定し→回帰係数で「どんな直線か」を求め→回帰直線で「その先を予測する」という3段階の流れを、選択肢に紛れ込む「本物だが場違いな値」に注意しながら通す。

問題

与えられたデータ

ある製品の強度yと、添加剤の量xとの間に直線的な関係があることが想定できる。20組(n=20)のデータから、偏差平方和と偏差積和はすでに計算済みで与えられている。

分散分析表を埋める — (18)〜(21)

回帰による変動SRは「単回帰分析の分散分析表」で見た通り、Sxy²/Sxxで最短に求まる。残差Seは合計Syyからの引き算。

回帰による変動 S(R) S(R) = S(xy)² / S(xx) = 729.1² / 82.2 = 531586.81 / 82.2 S(R) ≒ 6466.99
残差の変動 S(e)（引き算で求める） S(e) = S(yy) − S(R) = 6650.00 − 6466.99 S(e) ≒ 183.01
平均平方と分散比F(0) φ(R) = 1、φ(e) = n − 2 = 20 − 2 = 18 V(e) = S(e)/φ(e) = 183.01 / 18 ≒ 10.17 V(R) = S(R)/φ(R) = 6466.99 / 1 = 6466.99 F(0) = V(R) / V(e) = 6466.99 / 10.17 F(0) ≒ 635.89

STEP 2

選択肢の半分は「表とは無関係な本物の値」— (18)〜(21)の罠

この設問の10個の選択肢のうち4つ(ウ・オ・ク・コ)は、実は問題文に書いてある値をそのまま持ってきただけ。計算せずに表と数字が似ているものを選ぶと引っかかる。

STEP 3

回帰直線を求める — (23)(24)

傾きβ1はSxy/Sxx、切片β0は「回帰直線は必ず(x̄,ȳ)を通る」性質から、ȳ−β1x̄で求める。

傾き β̂(1) β̂(1) = S(xy) / S(xx) = 729.1 / 82.2 β̂(1) ≒ 8.87
切片 β̂(0)（回帰直線は必ず(x̄,ȳ)を通る） x̄ = 480.0/20 = 24.0、ȳ = 4440/20 = 222.0 β̂(0) = ȳ − β̂(1)・x̄ = 222.0 − 8.87 × 24.0 = 222.0 − 212.88 β̂(0) ≒ 9.12
(23) イ. 8.87 (24) ウ. 9.12
テンプレートの並び順に注意: 問題文の式は「ŷ = (24) + (23)x」、つまり先に切片(24)、後に傾き(23)の順で書かれている。β̂(1)=8.87を先に出してしまうと、そのまま(23)欄に置きたくなるが、式の中での位置は逆。計算した後に「どちらが切片でどちらが傾きか」を式に当てはめ直す一手間が要る。
STEP 4

回帰直線で予測する — (25)

求めた回帰直線に x=25.0 を代入するだけ。分散分析表・回帰係数のどちらも経由せず、直接この式に数字を入れるのが最短ルート。

x=25.0のときのyの母平均の点推定値 ŷ = β̂(0) + β̂(1)・x = 9.12 + 8.87 × 25.0 = 9.12 + 221.75 ŷ ≒ 230.9
(25) オ. 230.9
x=25.0は「ちょうどよい」値: データのx̄=24.0に近い25.0での予測なので、外挿(データ範囲の外に無理に伸ばす予測)にはあたらない。実際x=20.0〜27.0の範囲内なので、この点推定は妥当な内挿にとどまる。
要点

この問題から持ち帰ること

1S(xx)・S(yy)・S(xy)がすでに与えられていても、分散分析表の作り方は変わらない: S(R)=S(xy)²/S(xx)、S(e)=S(yy)−S(R)。
2選択肢に「問題文にすでに書いてある値」がそのまま紛れ込むことがある。計算せずに数字が一致するものを選ばない。
3自由度の取り違え(φ(e)=18をφ(T)=19と誤る)は、見た目では気づきにくい罠。表の行ごとの自由度を都度確認する。
4回帰係数はβ̂(1)=S(xy)/S(xx)（傾き）、β̂(0)=ȳ−β̂(1)x̄（切片、必ず(x̄,ȳ)を通る）。式中の並び順(切片が先)にも注意。
5点推定はできあがった回帰直線にxを代入するだけ。分散分析表の検定結果とは独立した、別の計算であることを意識する。
