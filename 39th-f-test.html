2つのラインの母分散を比べる — 分散比のF検定

AラインとBラインで製品のばらつき(母分散)に違いがあるかを調べる問題。分散分析(ANOVA)のF検定とよく似た式を使うが、目的は「水準間で平均に差があるか」ではなく「2つの分散そのものが等しいか」。棄却域の作り方に、この検定ならではの「大きい方を分子にする」というひと工夫がある。

問題

設定

ある工場で製造される製品について、AラインとBラインで母分散に違いがあるかを調べる。Aラインから8個、Bラインから9個をランダムに取り、分散比のF検定を行う。

サンプルサイズ n(A) = 8 → 自由度 φ(A) = n(A)−1 = 7 n(B) = 9 → 自由度 φ(B) = n(B)−1 = 8
STEP 1

仮説の設定と有意水準 — (8)(9)

調べたいのは「違いがあるかどうか」であって「どちらが大きいか」ではないので、対立仮説は両側(≠)になる。

仮説 帰無仮説 H(0): σA² = σB² 対立仮説 H(1): σA² ≠ σB² 有意水準 α = 0.05
(8) ア. σA² = σB² (9) イ. σA² ≠ σB²
一元配置実験のF検定との違い: 一元配置実験の分散分析(第36回 問5など)では対立仮説は「少なくとも1つの水準平均が異なる」で、検定は常に片側(F0が大きいときだけ有意)。今回は「2つの分散のどちらが大きいか」を決め打ちしない両側検定なので、棄却域の作り方も一手間増える。
STEP 2

棄却域Rの設定 — (10)(11)

F分布の表は上側の値しか載っていないことが多いため、両側検定でも分散が大きい方を分子にしてF0を常に1以上にするという工夫をする。どちらが分子になるかでF0が従うF分布の自由度の組み合わせが入れ替わるので、棄却域の境界値も2種類用意しておく。

分散の大小関係で場合分け VA ≥ VB のとき F0 = VA/VB, 棄却域 R: F0 ≥ F(φA, φB; 0.025) = F(7, 8; 0.025) VA < VB のとき F0 = VB/VA, 棄却域 R: F0 ≥ F(φB, φA; 0.025) = F(8, 7; 0.025)
(10) キ. F(7,8;0.025) = 4.53 (11) ク. F(8,7;0.025) = 4.90
なぜ0.025なのか: 両側検定でα=0.05を上下2つの裾に振り分けるので、片側あたりはα/2=0.025になる。「大きい方を分子にする」トリックのおかげで、実際に見るのは常に上側だけで済み、F表の下側(1未満)の値を別途探す必要がない。
STEP 3

統計量の計算 — (12)

各ラインの平方和から分散(平均平方)Vを求め、大小を比較してから比を取る。

各ラインの分散 SA = 5.875 → VA = SA/φA = 5.875/7 = 0.839 SB = 12.222 → VB = SB/φB = 12.222/8 = 1.528
VAとVBの大小比較 → どちらの場合分けを使うか
V大小
A0.839
B1.528VA < VB → F0 = VB/VA を使う
検定統計量 F0 = VB/VA = 1.528 / 0.839 = 1.820
(12) ウ. F0 = 1.82
STEP 4

判定 — (13)

VA<VBの場合なので、棄却域は(11)の F(8,7;0.025)=4.90 と比較する。

判定 F0 = 1.82 < 4.90 = F(8,7;0.025) → 棄却域に入らない → 有意でない
(13) キ. 有意でないので、母分散σA²とσB²は異なるとはいえない
「等しいといえる」ではない: 「有意でないので、母分散は等しいといえる」という選択肢は誤り。検定が有意でない=「差がある証拠が見つからなかった」だけで、「等しいと証明された」わけではない。仮説検定は「差がないことの証明」には使えないので、正しい結論は「異なるとはいえない」という消極的な表現にとどめる。
補足

「大きい方を分子にする」トリックを図で理解する

F分布は左右非対称なので、両側検定でも「下側5%点」と「上側5%点」の2つを別々に用意する必要がある。ところがF検定表には通常上側の値しか載っていない。そこで、VA/VBとVB/VAはちょうど逆数の関係にあることを利用し、常に1以上になる方(=大きい方÷小さい方)だけを計算して、上側の値とだけ比較すればよいことにする。

手順への影響: このトリックのせいで、どちらの自由度の組み合わせ(φA,φB)か(φB,φA)かは計算してみるまで確定しない。今回もSTEP2の時点では(10)(11)の両方を用意しておき、STEP3でVA・VBを実際に計算してから、どちらを使うか(今回は(11))を決めている。
要点

この問題から持ち帰ること

12群の母分散を比べる検定はF0=VA/VB(または逆数)。自由度は各群のn−1。
2「違いがあるか」を調べる検定は両側(H1: σA²≠σB²)。α=0.05なら片側あたりα/2=0.025を使う。
3両側検定の棄却域は、大きい分散を分子にしてF0を常に1以上にすることで、上側の棄却域だけの比較に置き換えられる。どちらの自由度の組み合わせを使うかは、VAとVBを計算してから決まる。
4有意でないという結論は「異なるとはいえない」であって「等しいといえる」ではない。仮説検定は差がないことの証明には使えない。
5一元配置実験のF検定(水準平均の比較)は常に片側検定。分散の等質性を調べる本問のF検定とは、同じF分布を使っても検定の組み立て方が異なることを区別する。
