QC検定2級 過去問解説 / 第35回 問3

相関係数から回帰直線、平方和の分解まで

電流値と溶接強度、15組のデータの要約統計量だけから、相関係数→回帰係数→散布図への当てはめ→分散分析のための平方和の分解、という単回帰分析の一連の流れを最初から最後まで解く。相関係数rと回帰係数β1、両者の式の違いを意図的に混同させる選択肢の作り方にも注目する。

問題

与えられた条件

ある溶接部品の電流値xと溶接強度yについて、15組の対応のあるデータから次の値を算出した。
n = 15 x̄ = 126.87 ȳ = 11.667 S(xx) = 265.73 S(yy) = 14.27 S(xy) = 58.13
STEP 1

相関係数を求める — (10)

相関係数は偏差積和を、xとyそれぞれの偏差平方和の幾何平均で割ったもの。分母はS(xx)とS(yy)の積の平方根であり、S(xx)だけで割るものではない。

相関係数 r = S(xy) / √(S(xx)·S(yy)) = 58.13 / √(265.73 × 14.27) = 58.13 / √3791.97 r ≒ 0.944
(10) オ. 0.944
(10)の誤答は別の公式と取り違えた値になっている
値判定原因
オ. 0.944正解r = S(xy)/√(S(xx)·S(yy))
ア. 0.219誤分母の√(S(xx)·S(yy))を忘れ、S(xx)だけで割った値(58.13/265.73)。実はこれは後で求める回帰係数β1の値そのもの
エ. 0.891誤r²=0.944²=0.891。寄与率(決定係数)を相関係数と取り違えた値
(10)の選択肢ア0.219は、後の設問(11)の正解と同じ数値。相関係数rと回帰係数β1は式が似ているため混同しやすいが、rは無次元で必ず−1〜1に収まるのに対し、β1は単位を持つ量で1を超えることもある。数値が同じに見えても意味が違う量であることを区別すること。
STEP 2

回帰直線をあてはめる — (11)(12)

単回帰モデル yi=β0+β1xi+εi に最小二乗法をあてはめる。傾きβ1を先に求め、それを使って切片β0を求める順序は崩さない。

傾き(回帰係数) β̂1 = S(xy) / S(xx) = 58.13 / 265.73 β̂1 ≒ 0.219
(11) エ. 0.219
切片 β̂0 = ȳ − β̂1·x̄ = 11.667 − 0.219 × 126.87 β̂0 ≒ −16.12
(12) ウ. −16.12
丸めの注意: 与えられたx̄・ȳ・各平方和はすでに小数点以下で丸められた値。これらをそのまま計算すると β̂0≒−16.09 になりやすく、選択肢の−16.12とわずかにずれる。これは元データの丸め誤差の蓄積によるもので、選択肢の中で最も近い値を選べばよい(36th-regression.htmlで扱った丸めの注意と同じ現象)。
(11)(12)の他の選択肢が対応する典型ミス
β1β0判定原因
エ. 0.219ウ. −16.12 正解 β1=S(xy)/S(xx)、β0=ȳ−β1·x̄
キ. 4.07ケ. 79.34 誤(ペア) xとyを取り違えた(yに対するxの回帰)。γ1=S(xy)/S(yy)=58.13/14.27=4.07、γ0=x̄−γ1·ȳ=126.87−4.07×11.667≒79.34
エ. 0.219コ. 124.31 誤 正しい傾き0.219を使いながら、切片の式でx̄とȳの役割を取り違えた(x̄−β1·ȳ=126.87−0.219×11.667≒124.31)
xとyを取り違える罠は単回帰の定番: 「電流値xで溶接強度yを説明する」のか「溶接強度yで電流値xを説明する」のかを逆にすると、傾き・切片ともに全く別の値になる。どちらの変数が原因(x)でどちらが結果(y)かを問題文で確認してから式を立てること。
STEP 3

散布図への当てはめを判定する — (13)

回帰直線 y = −16.12 + 0.219x を、選択肢のグラフ(x軸115〜135、y軸10〜14)の枠内でどう描かれるかを検討する。直線を式で決めてから、グラフの枠に収まる範囲を逆算するのがポイント。

グラフの枠(y軸最小値10)に入る前の値を確認 x=115 のとき: y = −16.12 + 0.219×115 = −16.12 + 25.19 = 9.07　(枠外、y軸最小値10を下回る) y=10 になるxを逆算: x = (10+16.12)/0.219 ≒ 119.3 x=135 のとき: y = −16.12 + 0.219×135 = −16.12 + 29.57 ≒ 13.44
結論 グラフに実際に描かれる線分は、x≒119.3の位置でy=10から立ち上がり、x=135でy≒13.4に達する
(13) エ
STEP 4

平方和の分解 — (14)(15)(16)(17)

回帰直線をあてはめることに意味があるかを統計的に判定するため、分散分析を用いる。そのために全変動S(yy)を2つに分解する。

平方和の分解 S(yy) = Σ(yi−ȳ)² = Σ(yi−β̂0−β̂1xi)² + Σ(β̂0+β̂1xi−ȳ)² 　　　= (14)平方和 + (15)平方和
1第1項 Σ(yi−β̂0−β̂1xi)² = Σ(yi−ŷi)² … 実測値と回帰直線上の予測値との差の2乗和。これは残差平方和。
2第2項 Σ(β̂0+β̂1xi−ȳ)² = Σ(ŷi−ȳ)² … 回帰直線上の予測値と全体平均との差の2乗和。これは回帰による平方和。
(14) カ. 残差 (15) ウ. 回帰による
(16) ア. 図3.1のAの長さ (17) イ. 図3.1のBの長さ
補足

回帰による変動S(R)は何通りにも書ける

今回のS(15)=回帰による平方和は、Σ(ŷi−ȳ)²という定義そのままの形で出題されたが、実際に計算するときはS(R)=S(xy)²/S(xx)やS(R)=β̂1·S(xy)のように、データを使わず要約統計量だけで求められる。これらが同じ値になる理由は「回帰による変動の求め方」で掘り下げている。また、平方和を要因ごとに分ける発想そのものは単回帰の分散分析表や、一元配置実験の自由度の数え方を整理した「自由度の正体」とも共通する構造である。

要点

この問題から持ち帰ること

1相関係数 r = S(xy)/√(S(xx)·S(yy))。分母はS(xx)だけでなくS(yy)との積の平方根。
2回帰係数 β1 = S(xy)/S(xx)。rと式が似ているが、意味も値も別の量。
3散布図への当てはめ問題は、回帰直線の式をまず求め、グラフの枠に入る範囲を逆算してから選択肢を絞る。
4平方和の分解 S(yy)=S(残差)+S(回帰) は、図で見ると1点ごとの「実測値→回帰直線→平均」の2区間分解に対応する。
5xとyを取り違える誤答は単回帰全般で頻出。どちらが説明変数(x)でどちらが目的変数(y)かを最初に確認する。
