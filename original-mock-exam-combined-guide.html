統合模試ウォークスルー

オリジナル模試 統合版(大問17問・148空欄)を、6つの出題分野ごとに横断して読み解くための資料。同じ分野の問題を模試1・2・3の間で並べると、毎回「状況は変わっても解き方の骨格は同じ」であることが見えてくる。各分野に図解と3問(QC的問題解決は2問)の比較を置いた。個別の計算の途中式は統合模試ページ内の「採点する」ボタンでも確認できるので、ここではその分野に共通する型と、間違えやすい分岐点に絞って整理する。

検定と推定

問1・問7・問13

「2つの数値を比べて差があると言えるか」を確かめる分野だが、比べる相手の"形"によって使う検定が変わる。統合模試はこの3パターンをちょうど1問ずつ当てている。

3つの検定の違い
問1 独立2標本問7 対応のあるデータ問13 母比率
データの形ラインA(n=10)とラインB(n=8)、別々のサンプル同じ8個のワークを新旧の治具で測定(差dを使う)同じ工程の不適合品率を、新標準の前後で比較
検定統計量t0=(x̄A−x̄B)/√{Ve(1/nA+1/nB)}t0=d̄/(sd/√n)z0=(p̂−p0)/√{p0(1−p0)/n}
自由度・近似φ=nA+nB−2=16φ=n−1=7標本サイズが大きいので正規近似
対立仮説の向き片側(上側): μA>μB片側(上側): μd>0片側(下側): 不適合品率が下がったか
問1・模試1

2つの母平均の差の検定(片側)

旧ラインA(n=10, x̄=52.3, V=4.20)と新ラインB(n=8, x̄=49.8, V=3.60)の破断強度。母分散が等しいとみなし、μA>μBといえるかを有意水準5%で検定する。

t(16,0.05)=1.746　t(16,0.025)=2.120
  1. φ = nA+nB−2 = 16
  2. Ve = {(nA−1)VA+(nB−1)VB}/φ = 63/16 = 3.94
  3. t0 = (x̄A−x̄B)/√{Ve(1/nA+1/nB)} = 2.5/0.9412 ≒ 2.656
t0(2.656) > t(16,0.05)(1.746) → 有意水準5%で有意(AがBより優れているといえる)。差の95%信頼区間は [0.50, 4.50] で0をまたがず、結論と整合する。
ここに注意: 片側の対立仮説なので棄却判定はt(16,0.05)。信頼区間は両側なのでt(16,0.025)を使う ― 同じ検定でも段階によって表引きの列が変わる。
問7・模試2

対応のあるデータの差の検定(片側)

同一8個のワークを旧治具・新治具の順に測定した寸法差d(Σd=18, Σd²=52)。μd=μ(新)−μ(旧)>0といえるかを有意水準5%で検定する。

t(7,0.05)=1.895　t(7,0.025)=2.365
  1. φ = n−1 = 7。Sd = Σd²−(Σd)²/n = 52−40.5 = 11.5
  2. Vd = Sd/(n−1) ≒ 1.6429、d̄ = 2.25、t0 = d̄/(√Vd/√n) ≒ 4.965
t0(4.965) > t(7,0.05)(1.895) → 有意水準5%で有意。95%信頼区間は [1.18, 3.32]。
ここに注意: 同一ワークを2つの治具で測るとワーク自体の個体差は両方の測定に同じように乗る。差dをとるとその個体差が打ち消され、治具の違いだけを高精度に検出できる ― これが2標本t検定でなく1標本の検定として扱う理由。
問13・模試3

母不適合品率の検定と区間推定

従来p0=5%だった不適合品率が、新標準導入後n=200個中x=6個(3.0%)になった。下がったといえるかを有意水準5%の片側(下側)検定で確かめる。

z(0.05)=1.645　z(0.025)=1.96
  1. p̂ = x/n = 6/200 = 0.030
  2. z0 = (p̂−p0)/√{p0(1−p0)/n} = −0.020/0.01541 ≒ −1.298
棄却域は z0<−1.645。z0(−1.298)は棄却域に入らず有意ではない(下がったとはいえない)。区間推定はp̂を使い、95%CI=[0.64%, 5.36%]。
ここに注意: 検定は帰無仮説p0の下での起こりにくさを測るのでp0を使い、区間推定は手元のデータから真の値を見積もるのでp̂を使う。母平均の検定でμ0を、信頼区間でx̄を使う関係とまったく同じ構造。

相関・回帰分析

問2・問8・問14

出発点は毎回同じ3つの平方和 S(xx)・S(yy)・S(xy)。そこから相関係数・回帰式・分散分析表までは一本道で求まる。統合模試の3問は、この一本道を①基本形で通しで使う(問2)、②無相関の検定とF0の関係まで掘り下げる(問8)、③信頼区間と予測区間の違いに焦点を当てる(問14)、という3方向に分けて出題している。

単回帰分析(一本道の基本形)

金型温度x(10水準)と収縮率yの関係(n=10)。相関係数から回帰式、分散分析表、信頼区間、予測値までを一通り求める。

Σx=55 Σy=185 Σx²=385 Σy²=4165 Σxy=1262
  1. Sxx=82.5、Sxy=244.5、Syy=742.5 → r=244.5/247.5≒0.988
  2. b=Sxy/Sxx≒2.96、a=ȳ−bx̄=2.20
  3. S_R=Sxy²/Sxx≒724.61、S_e=Syy−S_R≒17.89 → F0≒324.01(有意)
  4. R²=S_R/Syy≒0.976(r²と一致)。bの95%CI=[2.58, 3.34]
x=7を代入した予測値 ŷ = a+7b ≒ 22.95。
ここに注意: R²(寄与率)はr²と一致することを検算に使える。丸めた係数でなく、丸める前の値で最終計算をすると誤差が出にくい。
問8・模試2

単回帰分析と無相関の検定

処理時間x(8水準)とめっき厚みyの関係(n=8)。回帰の有意性を検定し、F0とt0の関係を確認する。

Σx=72 Σy=197 Σx²=816 Σy²=5575 Σxy=2120
  1. Sxx=168.0、Sxy=347.0、Syy≒723.88 → r≒0.995
  2. b≒2.07、a≒6.04
  3. S_R≒716.72、S_e≒7.15 → F0≒601.04(F(1,6;0.05)=5.99を大きく上回り有意)
R²=S_R/Syy≒0.990。x=9での予測値 ŷ≒24.63。
ここに注意: 単回帰では無相関の検定の統計量t0とこのF0の間に F0=t0² の関係が成り立つ(自由度も1:1対応)。どちらで検定しても同じ結論になる。
問14・模試3

母平均の信頼区間と個々の値の予測区間

熱処理炉の設定温度xと硬さyの関係(n=8)。x=8における(a)回帰直線上の母平均の95%信頼区間と(b)新たに1個測定したときの95%予測区間を両方求め、違いを確認する。

Σx=36 Σy=246 Σx²=204 Σy²=7964 Σxy=1236
  1. Sxx=42.00、Sxy=129.00、Syy=399.50 → b≒3.07、a≒16.93
  2. Ve=S_e/(n−2)≒0.55、x̄=4.5、ŷ(x=8)≒41.50
母平均の95%信頼区間: ŷ±t√{Ve(1/n+(x0−x̄)²/Sxx)} = [40.33, 42.67]。個々の値の95%予測区間: 式の中に「+1」が入り Ve(1+1/n+(x0−x̄)²/Sxx) = [39.34, 43.66]。
ここに注意: 信頼区間は「回帰直線そのものの位置」の不確かさだけを表す。予測区間はそれに加えて「1個の新しい観測値が平均のまわりにばらつく誤差」も上乗せする必要があり、これが式の+1に対応する。だから予測区間は必ず信頼区間より広い。

問3・模試1

X̄-R管理図と工程能力指数

樹脂パイプの外径(mm)、n=5×20日。規格はUSL=28.0mm、LSL=21.0mm。

ΣX̄=496.0 ΣR=36.0 A2=0.577 D4=2.114 d2=2.326
  1. X̄̄=496.0/20=24.80、R̄=36.0/20=1.80
  2. UCL/LCL(X̄)=24.80±0.577×1.80=[23.76, 25.84]。UCL(R)=D4R̄≒3.81、n≦6ではLCL(R)は引かない
  3. 第15群 X̄=27.90 はUCL超え → 異常
  4. σ̂=R̄/d2≒0.774、Cp=(USL−LSL)/6σ̂≒1.51、CPU≒1.38、CPL≒1.64 → Cpk=min=1.38
Cpk=1.38≧1.33 → 工程能力は十分である。ただしCPUがCPLより小さく、平均はやや上限規格側に寄っている。
ここに注意: n=5(n≦6)ではR管理図のD3が定義されずLCLを引かない ― 不適合を作る方向にしか変動しないと考えるため。
問9・模試2

np管理図と工程能力指数

毎日n=100個を検査、20日間の不適合品数合計80個。別特性はσ̂=0.42mm、X̄̄=24.90mm、USL=25.50mm、LSL=24.00mm。

n=100(一定) k=20 Σ(np)=80
  1. np̄=80/20=4.00、p̄=0.04
  2. UCL=4.00+3√(4.00×0.96)≒9.88。LCLは負になるため引かない(np管理図でも同じ発想)
  3. 21日目のnp=11はUCL超え → 異常
  4. Cp=(1.50)/(6×0.42)≒0.60、CPU≒0.48、CPL≒0.71 → Cpk=0.48
Cpk=0.48<1.00 → 工程能力は不足している。上限規格側の外れが多く出ている可能性が高い。
ここに注意: Cpkが低いとき、CPUとCPLのどちらが効いているかを見れば「平均がどちら側に寄っているか」まで読み取れる ― Cpの1つの数字だけでは分からない情報。
問15・模試3

群の大きさが一定でないp管理図

5日分の検査数n_iと不適合品数x_iが日によって変動する(n=80〜120)。p管理図では日ごとにUCL/LCLが変わる。

N=450 X=24 → p̄=0.0533
  1. 3日目(n=60): UCL=0.0533+3√(0.0533×0.9467/60)≒0.1404(LCLは負のため引かない)
  2. 4日目(n=120): UCL=0.0533+3√(0.0533×0.9467/120)≒0.1149
3日目のp=0.150はUCL(0.1404)を超え異常。4日目のp=0.050はUCL(0.1149)以下で安定。
ここに注意: 標準誤差√{p̄(1−p̄)/n}はnが大きいほど小さくなるため、群の大きさが変わるp管理図では同じp̄でも日によって管理限界の幅が変わる ― 検査数が小さい日ほど帯が広くなる。

実験計画法

問4・問10・問16

共通の発想は「全体のばらつき S_T を要因の効果と誤差に配分する」こと(回帰分析でS_TをS_RとS_eに分けるのと同じ構造)。統合模試は一元配置(繰返し不揃い)/二元配置(繰返しあり、交互作用を検定できる)/二元配置(繰返しなし=ブロック要因、交互作用が誤差と分離できない)という3パターンを出している。

一元配置実験(繰返し数が不揃い)

触媒A1(n=5)・A2(n=4)・A3(n=3、原料不足)の収率(%)。母平均に差があるかを検定し、最良水準の母平均を区間推定する。

N=12 T=996 Σx²=82906
  1. CT=T²/N=82668。S_T=82906−CT=238。S_A=Σ(T_i²/n_i)−CT=180。S_E=S_T−S_A=58
  2. φ(E)=N−a=9(合計はΣ(n_i−1)=9と一致)。F0=V_A/V_E=90/6.444≒13.97(有意)

問10・模試2

繰返しのある二元配置実験

温度A(3水準)×触媒B(2水準)、各組合せr=2、N=12。主効果と交互作用A×Bを有意水準5%で検定する。

N=12 T=896 Σx²=67276
  1. S_T≒374.67、S_A≒272.67、S_B≒85.33、S(A×B)≒4.67、S_e=12.00
  2. F0(A)≒68.17(有意)、F0(B)≒42.67(有意)、F0(A×B)≒1.17(有意でない)
交互作用が有意でないため、AとBの効果は独立(加法的)とみなせ、それぞれの主効果だけで最適水準を選んでよい。A2×B2が最適(実測セル平均も83.0で最大)。
ここに注意: 交互作用が有意な場合は主効果だけで最適水準を選べない(水準ごとの効果が独立に効かないため)。この判定を先にすることが、最適水準を選ぶ手順の分かれ目になる。
問16・模試3

繰返しのない二元配置実験

処理条件A(4水準)×原料ロットB(3水準、ブロック要因)、各組合せ1回のみ(N=12)。ロットの影響を取り除いたうえでAとBを検定する。

N=12 T=642 Σx²=34602
  1. S_T=255.00、S_A≒179.00、S_B≒51.50、S_e=S_T−S_A−S_B=24.50
  2. φ(A)=3、φ(B)=2、φ(e)=(a−1)(b−1)=6。F0(A)≒14.61(有意)、F0(B)≒6.31(有意)
処理条件A・原料ロットBともに有意。ブロック要因Bが有意ということは、ロットの違いを取り除いたことで誤差を小さくできたと解釈できる。
ここに注意: 繰返しが1回(r=1)だと各セルにデータが1個しかなく、「同じ条件を繰り返す誤差」を測る手段がない。交互作用A×Bの変動と誤差の変動を区別できないため、この配置では通常「交互作用はない」と仮定して分析するしかない。

統計的方法の基礎

問5・問11・問17

「観測される値がどんな確率分布に従うか」を見極め、確率や区間を計算する分野。抽出の仕方(復元か非復元か、有限母集団か)と、稀な事象か連続量かで使う分布が決まる。

問5・模試1

二項分布と正規分布の確率計算

(1)不適合品率3%の工程からn=10個抜取り。(2)重量が正規分布N(500,10²)、USL=515g、LSL=485g。

B(10,0.03)　N(500, 10²)
  1. Pr(X=0)=(0.97)^10≒0.737、Pr(X=1)≒0.228、Pr(X≧2)=1−(0.737+0.228)≒0.035(余事象)
  2. Z=(515−500)/10=1.50 → 片側外れ確率0.0668、左右対称なので両側合計=2×0.0668=13.36%
下位5%点 = 500−1.645×10 = 483.55g(上位5%点500+16.45=516.45gと混同しない)。
ここに注意: Pr(X≧2)を余事象で求めるとき、四捨五入した中間値を使うため直接計算とわずかにズレる ― 丸め誤差の範囲であり計算ミスではない。
問11・模試2

超幾何分布と中心極限定理

(1)ロット20個中不良品3個から5個抜取り(非復元)。(2)σ=15gの工程からn=25個、x̄=120g。

₂₀C₅=15504
  1. Pr(X=0)=₃C₀・₁₇C₅/₂₀C₅≒0.399、Pr(X=1)≒0.461、Pr(X≧1)=1−0.399=0.601
  2. 標準誤差=σ/√n=15/5=3.00g。母標準偏差既知なのでt分布でなくz(0.025)=1.96を使う
95%CI = 120±1.96×3.00 = [114.12, 125.88]g。
ここに注意: 中心極限定理により、母集団の分布の形によらず標本サイズnが十分大きければ標本平均の分布は近似的に正規分布N(μ,σ²/n)に従う ― これがσ既知ならz値で区間推定できる根拠。
問17・模試3

ポアソン分布による欠点数の確率計算

織物1m²あたりの欠点数がλ=2.5のポアソン分布に従う。

Pr(X=k)=e^(−λ)λ^k/k!　λ=2.5
  1. Pr(X=0)=e^(−2.5)≒0.082、Pr(X=1)≒0.205、Pr(X=2)≒0.257
  2. Pr(X≧3)=1−(0.082+0.205+0.257)≒0.456(余事象)
面積が4倍になれば期待値も比例して4倍 → λ=2.5×4=10.0個。
ここに注意: ポアソン分布は「試行回数nが非常に大きく、事象の起こる確率pが非常に小さい」という条件で、np=λを一定に保ったまま二項分布の極限をとったときに得られる ― 理論上の試行回数を数えにくい現象(単位面積あたりの欠点数など)に向く。
6/6

QC的問題解決

問6・問12

層別してクロス集計して初めて見える「真因」を読む問題。行合計・列合計だけを見ても、実際に効いている組合せは見えない ― これがこの分野の核心で、問6・問12は同じ構造の題材を別のデータで出題している。

問6・模試1

層別で読む不適合の発生状況(機械×勤務帯)

機械A・B・Cと昼勤・夜勤で層別した「キズ」発生件数。次の調査の方向性を考える。

機械A:昼12/夜8=20　機械B:昼5/夜6=11　機械C:昼3/夜16=19　計:昼20/夜30=50
  1. 最多セルは機械C×夜勤(16件)。機械別合計の最大は機械A(20件)、勤務帯別合計の最大は夜勤(30件)
  2. 機械別上位2つ(A=20, C=19)の合計39/50=78%
次の一手は機械C×夜勤に絞ってさらに層別データを集めること。母集団を広げて全機械・全勤務帯を調べ直すのは、すでに得られている手がかりを無視することになる。
ここに注意: 「機械別に見るとAが最多」「勤務帯別に見ると夜勤が最多」という単独の集計結果につられて機械Aや夜勤全体を疑うと、本当の偏り(機械Cと夜勤の組合せ固有の原因)を見落とす。
問12・模試2

層別で読む「色ムラ」不適合の発生状況(機械×用紙)

印刷機X・Y・Zと用紙種類(コート紙・上質紙)で層別した色ムラの発生件数。問6と同じ考え方をあてはめる。

機械X:コート12/上質4=16　機械Y:コート5/上質15=20　機械Z:コート3/上質7=10　計:コート20/上質26=46
  1. 最多セルは機械Y×上質紙(15件)。機械別合計の最大は機械Y(20件)、用紙別合計の最大は上質紙(26件)
  2. 機械別上位2つ(Y=20, X=16)の合計36/46≒78%
機械別・用紙別の単独集計だけでは、機械Xと機械Yで「どちらの用紙が多いか」が逆転していることに気づけない。次は機械X×コート紙・機械Y×上質紙のそれぞれの組合せに絞って層別データを集めるのが合理的。
ここに注意: 問6は1つのセル(機械C×夜勤)に真因が集中していたが、問12は2つのセル(機械X×コート紙、機械Y×上質紙)にそれぞれ固有の偏りがある ― 「クロス集計が必要」という結論は同じでも、絞り込む先は1箇所とは限らない。
