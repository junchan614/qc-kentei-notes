QC検定2級 過去問解説 / 第37回 問6

ヒストグラムから工程能力指数、そして不適合率へ

休止していたラインBを再稼働したら、平均は規格の中心から右にずれ、ばらつきも通常ラインより大きかった――という設定。区間幅の決め方 → 平均のずれ・標準偏差の推定 → Cp → 正規分布での不適合率まで、1本の計算がそのままつながっている。最後の選択肢には「前の設問の答えがそのまま紛れ込んでいる」という、この問題ならではの罠がある。

問題

与えられたデータ

特性Qの規格は 8.70 ± 0.30（下限規格 SL=8.40、上限規格 SU=9.00）。通常ラインAと再稼働ラインBから、1日2サンプル×25日分＝各50個ずつ(合計n=100)のデータを取った。

表6.1 特性Qのデータ表（集計値）
ライン例数 n合計 Σx2乗和 Σx²
通常ラインA50434.963784.2832
再稼働ラインB50441.183893.6556

全体(n=100)の最大値 xmax=9.08、最小値 xmin=8.50。測定単位 m=0.02。

STEP 1

ヒストグラムの区間幅を決める — (33)

仮の区間数を k = √n として、区間幅の目安を出す。目安の値をそのまま使わず、測定単位 m の整数倍に切り上げるのが決まり――境界線がちょうどデータの値と重ならないようにするため。

区間数と区間幅 k = √n = √100 = 10 範囲 R = x(max) − x(min) = 9.08 − 8.50 = 0.58 目安の幅 = R / k = 0.58 / 10 = 0.058 0.058 を m=0.02 の整数倍に切り上げ → 0.02 × 3 = 0.06
(33) h = 0.06
もし別の区間数の決め方(スタージェスの公式)を使うと: k = 1 + 3.32×log₁₀(n) = 1 + 3.32×2 ≒ 7.64 ≒ 8。この場合は h = 0.58/8 = 0.0725 → 切り上げて 0.08 になり、選択肢のクに落ちる。「区間数をどの式で決めたか」で答えが変わるのがこの設問の面白いところ。QC検定では k=√n を基本として覚えておく。
STEP 2

ラインBの偏り・ばらつき・工程能力 — (34)(35)(36)

ヒストグラムを見比べると、ラインBの山は規格の中心よりも右に寄り、裾も広い。これを実際の数値で裏づける。

(34) 規格の中心値からの偏り x̄(B) = Σx(B) / n = 441.18 / 50 = 8.8236 偏り = x̄(B) − 8.70 = 8.8236 − 8.70 偏り ≒ 0.124
(35) 標準偏差の推定値 s(B) S(B) = Σx(B)² − (Σx(B))²/n = 3893.6556 − 441.18²/50 　　 = 3893.6556 − 3892.795848 = 0.859752 s(B) = √{ S(B) / (n−1) } = √(0.859752 / 49) = √0.017546 s(B) ≒ 0.132
(36) 工程能力指数 C(p)(B) C(p)(B) = (S(U) − S(L)) / (6 × s(B)) = (9.00 − 8.40) / (6 × 0.132) 　　 = 0.60 / 0.792 C(p)(B) ≒ 0.758
(34) 0.124 (35) 0.132 (36) 0.758
C(p)=0.758 の意味: 一般に C(p)<1.0 は「規格の幅に対してばらつきが大きすぎる、工程能力不足」の目安とされる。しかも平均自体も右に偏っているので、実際に規格を外れるリスクは C(p) の数字が示す以上に高い――だからこそ次の設問で「実際どれだけ規格を超えるのか」を正規分布で直接確認する。
STEP 3

上限規格を超える確率 — (37)

ラインBの分布を N(x̄(B), s(B)²) の正規分布とみなし、上限規格 S(U)=9.00 を超える確率を求める。標準化してZ表(正規分布表)を引く、という統計の基本操作そのもの。

標準化してZ値を求める Z = (S(U) − x̄(B)) / s(B) = (9.00 − 8.8236) / 0.132 　 = 0.1764 / 0.132 Z ≒ 1.33
正規分布表を引く Φ(1.33) = 0.9082　（Z=1.33以下の割合） 上側の確率 = 1 − Φ(1.33) = 1 − 0.9082 ≒ 0.0918 → 9.18%
(37) 約 9.18%
補足

Cpをもっと深く — 片側規格とC(pk)

本問の Cp(B)=0.758 は「規格が両側にあり、かつ工程は中心に来ている」という前提の指数にすぎない。実際にはラインBは中心からズレているので、Cp だけでは本当の余裕がわからない。ここを掘り下げる。

なぜ分母は「6σ」なのか — 両側規格の考え方 C(p) = (S(U) − S(L)) / 6σ = 規格の幅 ÷ 工程のばらつきの幅 「±3σの範囲にほぼ全データが収まる」という前提のもと、6σ(=3σ×2)を規格の幅と比べている

規格が片側にしかないとき（例: 不純物は少ないほど良い→上限のみ、強度は高いほど良い→下限のみ）は、SLやSUの片方が存在しないので Cp の式自体が使えない。この場合は片側指数を使う。

片側規格のときの指数 上限規格しかないとき: C(pu) = (S(U) − x̄) / 3σ 下限規格しかないとき: C(pl) = (x̄ − S(L)) / 3σ 分母が3σなのは、中心から片方向だけを見ているから（両側なら3σ+3σ=6σ）

そして規格が両側にあっても平均が中心からズレているときは、両側の片側指数を両方計算して、厳しい方（規格に近い方）を採用する。これが Cpk。

C(pk) — 偏りを考慮した「実力」の指数 C(pk) = min{ C(pu), C(pl) } C(pu) = (9.00 − 8.8236) / (3 × 0.132) = 0.1764 / 0.396 = 0.4455 C(pl) = (8.8236 − 8.40) / (3 × 0.132) = 0.4236 / 0.396 = 1.0697 C(pk)(B) = min(0.4455, 1.0697) = 0.446　（上限側が支配的）
C(p) と C(pk) の見え方の違い
指数値意味
C(p)(B)0.758「規格の幅」対「ばらつきの幅」だけを見た潜在能力。偏りは無視
C(pk)(B)0.446偏りまで考慮した実際の実力。上限側にしか目を向けていないぶん、より厳しい数字になる
C(pu)とZ値は同じものの言い換え: C(pu) = (S(U)−x̄)/3σ を3倍すると (S(U)−x̄)/σ になり、これはSTEP3で使ったZ値そのもの。実際 3×0.4455=1.337≒1.33=Z。「片側指数を3倍すればZ値になる」という関係を知っておくと、C(pu)やC(pl)が低いほど正規分布の裾の確率(不適合率)が大きくなる、というつながりが一直線に見える。Cp系の指数と不適合率の計算は、実は同じ「規格までの距離をσ何個ぶんで測るか」という発想の裏表にすぎない。
目安（QC検定でよく使われる基準）: Cp・Cpk ともに 1.33以上で十分、1.00〜1.33でまずまず(要注意)、1.00未満は工程能力不足で対策が必要とされる。ラインBは Cp=0.758 の時点ですでに不足気味だが、偏りを考慮した Cpk=0.446 まで落ちると「まずまず」の域からも大きく外れる、明らかに対策が必要な工程だとわかる。Cpだけを見て安心してはいけない理由がここにある。
分析

要点

この問題から持ち帰ること

1ヒストグラムの区間幅は h = R/k の目安値を出してから、測定単位mの整数倍に切り上げる。区間数kの決め方(√n かスタージェスの公式か)で答えが変わることを覚えておく。
2標準偏差の推定値は s = √{ (Σx² − (Σx)²/n) / (n−1) }。分散分析の誤差分散と同じ「2乗和を自由度n−1で割る」計算。
3工程能力指数 C(p) = (S(U)−S(L)) / 6s。C(p)<1.0 は規格幅に対してばらつきが大きすぎるサイン。
4正規分布で規格外れの確率を求めるときは Z = (規格値 − 平均) / 標準偏差 と標準化してから正規分布表を引く。平均が規格の中心からずれているほど、片側の裾は大きくなる。
5一連の計算でつながる問題では、選択肢に「前の設問の正解」がそのまま紛れ込むことがある。今どの単位・どの意味の値を求めているのかを毎回確認する癖をつける。
