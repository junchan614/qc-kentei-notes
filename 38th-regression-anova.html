単回帰分析 — 分散分析表から信頼区間まで

物質Aの濃度(x)から物質Bの質量(y)を予測する単回帰分析。偏差平方和 → 分散分析表 → 寄与率 → 有意性判定 → 回帰係数の信頼区間という単回帰の一連の流れを、20組のデータで最初から最後まで通す。「単回帰分析の分散分析表」で学んだ土台がそのまま使える。

問題

与えられたデータ

物質Aの濃度x(%)と物質Bの質量y(kg)のデータが20組(n=20)与えられ、各データのx²・y²・xyまで補助表として計算済み。必要なのはその合計値だけ。

表4.1 補助表の合計値（n=20）
ΣxΣyΣx²Σy²Σxy
237.937.23542.8388.26546.70
STEP 1

偏差平方和・偏差積和を求める — (22)(23)(24)

単回帰分析の出発点は毎回同じ3つの式。2乗和から「合計²/n」を引くという、これまでの分散分析と全く同じ操作。

S(xx) — xの偏差平方和 S(xx) = Σx² − (Σx)²/n = 3542.83 − 237.9²/20 = 3542.83 − 2829.8205 S(xx) ≒ 713.01
S(yy) — yの偏差平方和 S(yy) = Σy² − (Σy)²/n = 88.26 − 37.2²/20 = 88.26 − 69.192 S(yy) ≒ 19.07
S(xy) — xとyの偏差積和 S(xy) = Σxy − (Σx)(Σy)/n = 546.70 − (237.9×37.2)/20 = 546.70 − 442.494 S(xy) ≒ 104.21
(22) S(xx) = 713.01 (23) S(yy) = 19.07 (24) S(xy) = 104.21
STEP 2

分散分析表を作る — (25)(26)

回帰による変動 SR は「回帰による変動の4通りの求め方」で見た通り、Sxy²/Sxx が最短ルート。残差の変動 Se は Syy からの引き算で出す。そこまで出せば、分散比F0まで一気に埋められる。

回帰による変動 S(R) S(R) = S(xy)² / S(xx) = 104.21² / 713.01 = 10859.72 / 713.01 S(R) ≒ 15.23
残差の変動 S(e)（引き算で求める） S(e) = S(yy) − S(R) = 19.07 − 15.23 S(e) ≒ 3.84
平均平方と分散比F(0) V(R) = S(R)/φ(R) = 15.23/1 = 15.23 V(e) = S(e)/φ(e) = 3.84/18 ≒ 0.21 F(0) = V(R) / V(e) = 15.23 / 0.21 F(0) ≒ 72.52

自由度の数え方はいつもの単回帰の型: 回帰の自由度は説明変数の数(=1)で固定、残差はn−2、合計はn−1。n=20のとき残差の自由度は18――これが後の(28)(29)でF表・t表を引くときの行番号になる。V(e)を0.21(小数第2位)に丸めてからF(0)を計算するのがこの表の流儀で、丸めずに計算すると71台の値になり選択肢と合わなくなるので注意。
STEP 3

寄与率と有意性の判定 — (27)(28)

寄与率R²は「全体の変動のうち、回帰で説明できた割合」。SR/Syy で求める――これも分散分析表を作ったときの構造そのもの。

寄与率 R² R² = S(R) / S(yy) = 15.23 / 19.07 R² ≒ 0.7986
(27) R² = 0.7986
F(0)とF表による有意性の判定 F表より F(1, 18; 0.01) ≒ 8.29 F(0) = 72.52 ≫ 8.29 なので、有意水準1%でも棄却できる
(28) 高度に有意である
寄与率0.7986の実感: 「物質Aの濃度のばらつきだけで、物質Bの質量のばらつきの約80%が説明できる」という意味。残り約20%は、この単回帰モデルに含まれない別の要因や測定誤差によるもの。R²が1に近いほど直線関係が強い。
STEP 4

回帰係数の95%信頼区間 — (29)

回帰係数(傾き) b の区間推定は、「母平均の区間推定」と同じ「推定値 ± t × 標準誤差」の型。標準誤差の中身だけが回帰特有の形になる。

傾き b の推定値 b = S(xy) / S(xx) = 104.21 / 713.01 b ≒ 0.1461
傾きの標準誤差と信頼区間 SE(b) = √( V(e) / S(xx) ) = √(0.21 / 713.01) ≒ 0.0172 t(18, 0.025) = 2.101 β(1) の95%信頼区間 = b ± t×SE(b) = 0.1461 ± 2.101×0.0172 = 0.1461 ± 0.0361 0.1100 〜 0.1822
(29) 0.1101 〜 0.1823
分析

(25)(26)の選択肢は、実は5つとも「本物の値」

(25)(26)の5つの選択肢を並べると、どれか1つが計算ミスの産物というわけではなく、5つとも計算の途中で実際に登場する値で構成されている。違うのは「どのマスの値か」だけ。

(25)(26) の選択肢 — 全部が計算チェーンの中の実在の値
選択肢判定本当は何の値か
ア. 0.21誤V(e)（誤差の平均平方）。F0を求める途中の値であって、F0そのものではない
イ. 3.84誤S(e)（残差の変動）。回帰の行ではなく残差の行の平方和
ウ. 15.23正解 (25)S(R) = S(xy)²/S(xx) で正しく計算
エ. 19.07誤S(yy)そのもの。回帰の行ではなく合計の行の平方和
オ. 72.52正解 (26)F(0) = V(R)/V(e) で正しく計算
読み解き方: ア(Ve)・イ(Se)・エ(Syy)は、すべて分散分析表の中の「別のマスの値」であり、計算はどれも正しい。1つの表で複数の値を求める問題では、電卓の答えが合っているかどうかより先に「今どのマスを埋めているか」を指差し確認する方が事故が少ない。
要点

この問題から持ち帰ること

1単回帰の出発点は毎回同じ: S(xx)=Σx²−(Σx)²/n、S(yy)=Σy²−(Σy)²/n、S(xy)=Σxy−ΣxΣy/n。
2回帰による変動は S(R)=S(xy)²/S(xx)、残差は引き算(S(yy)−S(R))で求めるのが速い。自由度は回帰=1、残差=n−2、合計=n−1で固定。
3寄与率は R²=S(R)/S(yy)。分散分析表がすでにあれば追加の計算はほぼ不要。
4有意性の判定は分散分析(F検定)と同じ型: F(0)=V(R)/V(e) をF表と比較する。V(e)を丸めてから割ると選択肢のきれいな値に一致することが多い。
5回帰係数の信頼区間は b ± t(n−2,0.025)×√(V(e)/S(xx))。「1つの母平均の区間推定」と同じ「点推定 ± t×標準誤差」の型に、回帰特有の標準誤差を当てはめただけ。
61つの分散分析表の中で複数の値を問われるときは、選択肢に「表の別のマスの値」が紛れ込む。どの量を求めているかを都度確認する。
